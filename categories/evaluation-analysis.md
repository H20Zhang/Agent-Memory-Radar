# Evaluation & Analysis

[Research Map](../README.md#research-map) · [All research problems](README.md) · [Reading Paths](../README.md#reading-paths)

How to tell whether persistent memory is actually useful, economical, authorized, safe, and causally responsible for downstream behavior.

## Current argument

Memory evaluation is moving from **endpoint score → promotion evidence**. **D²ACCI** makes paired effects, protected slices, and stage-localizable traces part of feature promotion. **Competence, Not Accuracy** adds a precondition for reference-free skill gates: within-question discriminability on the actual optimization distribution, because marginal accuracy can be difficulty-confounded. **Remember, Verify, or Ask?** moves the authority check before writing, while **MemTrapBench** moves harm measurement after retrieval to the consumer's applicability decision. Both are synthetic early signals: the first does not execute commitment actions; the second deliberately constructs standalone-solvable queries with trap-inducing history. **Explicit State Elicitation Is Not Enough** supplies the complementary negative result that interpretable state need not improve policy. **Demystifying Agent Skills** separates representation, retrieval, invocation, and execution. **Total Recall**, **AuthMem-Bench**, **SkillJack**, and **Practice Makes Unsafe** extend the vector to lifecycle cost, authority, provenance, and descendant-state harm.

**Biggest unresolved question:** what deployment-facing evidence vector can decide whether a memory mechanism or gate deserves promotion without collapsing causal stage, gate discriminability, commitment authority, useful-memory retention, trap rejection, lifecycle cost, protected-slice regressions, and descendant-state risk into one score?

**Next decisive evidence:** long-running tool-use deployments with paired interventions, executed commitment actions, mixed memory-required/neutral/trap cases, within-item gate audits, stage traces, explicit protected slices, full offline+online cost, authority/revocation checks, and downstream action outcomes.

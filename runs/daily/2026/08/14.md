## Skeptical-review corrections

**ReFind:** do not summarize the result as “BM25 beats graphs.” The paper's strongest evidence is a matched interface control: generic iterative BM25 is still 14.5/7.1 points below full ReFind on LongMemEval-S/M, and the full system pays substantial query-time token/latency cost. The durable conclusion is that structured-memory papers need a competent raw-record search baseline.

**QCR:** the evidence isolates post-retrieval reuse more strongly than the exact four-field schema. Candidate selection is already strong (94.8% reusable), and QCR is only 1.8 points behind oracle selection, but the schema fields are not independently ablated. Length-group effects are not causal because task difficulty changes with trajectory length.

**Practice Makes Unsafe:** unsafe artifact creation is not identical to later harm—21 evolved configurations author unsafe skills but only 15 produce fresh-session harm. This stage separation is the contribution. SafeEvolve's aggregate benign utility is close to raw evolution, but individual utility/safety trade-offs remain.

**LycheeMemory V2:** the key causal decomposition is not “typed records are better.” Eager construction uses far more tokens and is worse; fixed-window batching is cheaper but also worse. This supports two distinct mechanisms: batching reduces construction frequency, semantic boundaries preserve coherent evidence.

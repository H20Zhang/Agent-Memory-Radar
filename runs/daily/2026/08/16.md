## Skeptical-review corrections

**RippleMem:** do not frame the result as “graphs beat raw memory.” ReFind remains the stronger warning against weak flat baselines. RippleMem earns 4/5 because its best control gives RF-Mem the same extracted memory units and evidence budget, while planned associative recollection still improves LoCoMo judge accuracy **83.83→87.14**. The durable claim is **evidence completion**, not graph structure by itself.

**SkillEvo:** the 81.8% final score is a package result, but the matched feedback-source ablation is more informative: replacing multi-turn interaction with single-turn QA gives **66.4%** while keeping attribution/revision/governance otherwise aligned. Governance has a smaller score effect (**78.6% without it**) but a much larger bloat-control effect (**+2.8% vs +16.2%**), so capability gradient and state governance should not be conflated.

**ERSkill:** the headline gains combine memory construction, skill search, frontiers, and router learning. The strongest mechanism evidence comes from ablations: removing skill evolution or the learned router causes the largest losses. The paper therefore supports **evolvable access programs** more strongly than any one frontier/trie detail.

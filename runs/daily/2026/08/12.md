## Skeptical-review corrections

**Agent Memory Distillation:** the useful claim is not “hierarchical memory wins.” The same teacher experience is reorganized into workflow/subtask/function memories and delivered at different control points. The largest reported contribution comes from subtask memory, and teacher quality is insufficient without student compatibility. The note therefore frames AMD as **consumer-aligned, training-free capability transfer**, not generic hierarchical-memory superiority.

**PMCoder:** the headline +5.0pp SWE-bench result is not enough to attribute causality because several mechanisms move together. The stronger evidence is the 2×2 planner×memory study: plan-only +1.3pp, memory-only +1.7pp, full +5.0pp, with a reported +2.1pp interaction. The note still flags execution grounding/edit recovery as not separately isolated.

**MERIT:** the paper's “causal” terminology refers to temporal eligibility of earlier finalized episodes, not causal attribution. More importantly, the structured design is not reliably separated from untyped dynamic retrieval; this negative result is surfaced as the main interpretation rather than hidden behind Spider gains.

## 一句话结论

本周没有出现足以确立新 memory architecture 的证据。更明确的变化是：**持久状态影响后续使用方之前，证据补全、技能选择、judge 资格、harness 提交和训练侧经验复用都需要各自的准入判断**。

## 实际发生了什么变化

### 1. 多源记忆需要单独控制证据补全

**MemFuse** 在拼接分散证据时保留 source provenance，但最大 ablation 来自 answer-time retrieval loop，而不是 graph construction 或 fusion。完整系统的三组总分为 **0.4659 / 0.4574 / 0.4698**；移除 agentic retrieval 后下降 **0.1036**，明显大于移除 graph/fusion 的总体影响。

**研究含义：** fused store 不能替 access loop 领取因果增益。下一项最接近的对照应当使用保留 provenance 的原始或最小变换 archive，匹配 iterative search、最终 evidence budget，以及完整 ingest 与 serving 成本。

### 2. Procedural-memory 更新要拆开 selector、judge 与 commit gate

三篇论文观察的是不同 gate，不能合并成同一趋势。

- **SkillGate** 在固定 skill file 暴露给 policy 之前加入 oracle-local selector channel。Success 从 **47.0%→53.2%**，oracle exposure 从 **54.3%→83.9%**，misleading exposure 从 **69.6%→21.8%**。但 intervention 同时改变 privileged utility label、read-call masking 和 selector-mass normalization，不能归因给单一 credit mechanism。
- **Competence, Not Accuracy** 检查 reference-free judge 在它将要管理的 paired candidate distribution 上是否真有判别力。控制 item difficulty 后，factual-QA AUC 从 **0.855→0.735**；research-math 的 within-question AUC 为 **0.489**，接近随机。
- **Harness Continual Learning** 把整个 non-parametric harness，而不是 memory component，作为 commit unit。加入 historical-loss bound 后，最终总分从 unrestricted 的 **60.13** 提升到 `b=1` 的 **63.46**；较窄的 memory-update ablation 为 **62.28 / 0.83 forgetting**，Full HCL 为 **63.41 / 0.45**。

**研究含义：** 选择持久 procedure、评估 candidate update、提交共同适应的 harness 是三个不同阶段。System-level score 不能把整个 package 的增益归给 memory。

### 3. 持久状态也可以位于部署之前，用来生成训练经验

**SPADE** 跨 training episode 保存可执行环境与 regret metadata，并为下一次 Environment Designer prompt 检索少量同 skill 示例。八个 game benchmark 上，full run 的 selected checkpoint 平均 **58.3**，官方 no-memory launcher 为 **53.2**；AIME 2026 则从无记忆的 **75.0** 降到有记忆的 **74.4**。

**研究含义：** training-side memory 应与部署期 actor memory 分开核算。当前证据只是一次 package ablation：single run、按同一 suite 选择 checkpoint、demonstration token 未配平、compute 未报告，因此不能归因给 regret ranking、200 条 buffer 或 FIFO retention。

## 需要继续追踪的张力

- **组织与访问：** MemFuse 让 fused provenance 可检查，但被测增益主要来自 answer-time evidence completion。
- **局部监督与开放技能库：** SkillGate 的 verified single-oracle 条件尚未覆盖会演化、可组合或相互冲突的 skill pool。
- **Gate 可解释性与真实判别力：** 一个 judge 可以在 aggregate metric 上显得合理，却不能完成准入所需的同题比较。
- **Memory component 与 state package：** HCL 和 SPADE 都包含持久记忆，但 headline outcome 来自共同适应的训练系统。

## 本周暴露出的研究缺口

最有价值的下一项实验是端到端 **persistent-state promotion protocol**：固定 actor、candidate stream 与任务，独立改变 access、selection、judge、commit 和 rollback，并报告 paired downstream behavior、protected-slice regression、provenance，以及完整 ingest/access/maintenance cost。

第二个缺口是多 seed 与自然演化 workload 的复现。本周五个方向都只得到单篇、窄 intervention family 的支持；没有任何一个达到修改长期 Field Map 的门槛。

## 下一步应观察什么证据

如果 provenance-preserving fusion 能胜过匹配的 iterative raw-state controller，selector-local supervision 能迁移到非 oracle skill，judge 资格可以预测更安全的真实 commit，guarded harness update 能经受更长状态流，且 training-side memory 能胜过 token-matched static、random 与 score-shuffled replay，本周判断会增强。

如果这些差异在匹配 prompt length、selection budget、judge distribution、seed variance 和完整 lifecycle cost 后消失，本周判断应当减弱。

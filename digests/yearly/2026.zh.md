# Agent Memory 年度综合 — 2026

[English](2026.md) · [全部研究压缩](../README.zh.md)

**状态：** 滚动至 2026-08-24。
**覆盖：** 主动整理始于八月，并回填一篇 2026-07-25 论文；这不是完整全年重建。

## 当前年度判断

在有限覆盖内，agent memory 正从 retrieval add-on 变成 **multi-stage state interface**：

`archive/representation → access program → evidence completion/selection → operative/consumer state → update/governance → lifecycle cost/provenance`

最稳定的方法论修正是：**复杂度只应在 matched simpler alternative 失败的 stage 获得 credit。** ReFind 抬高 raw-record baseline；RippleMem 说明 structure 在 bounded evidence completion 中仍可能有价值。QUMem/QCR 区分 retrieved evidence 与 actor-facing state。SkillEvo、ERSkill 与 HyperSkill 把 adaptive state 放到 feedback、access policy 与 operational structure。

最新 early signal 没有建立新趋势。MemFuse 的最大作用在 iterative access；SkillGate 改变 procedural-memory exposure 但未隔离 credit；Competence 审计 gate 本身；HCL 把整个 harness 作为 guarded commit；SPADE 把 bounded memory 放在 training curriculum generator。8 月 24 日又增加 candidate commitment、state supersession 与 consumer applicability 三个相邻边界，但各自仍只有一篇支撑。

## 当前覆盖中可见的长期变化

### Precomputed representation → controllable evidence interface

V-Mem/MESA 说明关系与 view 只有在 access policy 使用时才有意义。ReFind 证明 competent raw-record interface 可以替代大量预处理；RippleMem 则表明，当 retrieved memory 成为 missing-evidence search 的 anchor 时，structure 仍可能赢过更匹配的 flat control。

**当前解释：** 默认基线应是对 minimally transformed evidence 的 competent access；structure 必须证明一个 online search 无法以更低全周期成本恢复的 operation。

### Fixed access → evolvable read programs

ERSkill 把 retrieval behavior 变成 persistent executable skill，HyperSkill 让 relation 参与 retrieval、ranking 与 maintenance。HyperSkill 的 ablation 同时移除 structure 与 access path，因此更支持 package 而非 hypergraph representation 本身。

**当前解释：** adaptive memory state 可以位于 read program；stored structure 只有被该 program 消费时才有价值。

### Candidate commitment → operative state → consumer applicability

MCB 在写入前区分 persist、ephemeral、verify 与 clarify，但不执行这些动作。StateMem 把 superseded value 退出 active state，并要求 dependent value 重算；其 dependency propagation 不稳定，强 wrapper 结果属于 answer-time full-transcript tracing。QUMem/QCR 说明 retrieved evidence 还需转成 query-conditioned consumer state。MemTrapBench 则提醒 relevant history 也可能不适用，但只测 trap-rich synthetic distribution。

**当前解释：** archived memory、retrieved evidence、current operative state 与 actor-facing applicable state 可以是四个不同对象，需要各自的 control 与成本核算。

### Self-improvement → feedback-rich, governed state transition

SkillEvo 强调 multi-turn feedback，WER 学 writer policy，TRUSS 做 executable artifact certification，ERSkill 演化 read policy，HCL 管理 whole-harness commit，SPADE 让先前环境影响未来 curriculum。Practice Makes Unsafe 与 SkillJack 则暴露 lineage、revocation 与 descendant-state risk。

**当前解释：** memory evolution 需要说明 failure signal、被改变的 persistent state、promotion gate 与 descendant governance；training-side 与 deployed memory 是不同 stage。

### Adaptive write granularity → lifecycle economics

LycheeMemory V2 隔离 cadence，FTA-Mem 说明最佳 persistent unit 随 evidence density 改变，Total Recall 证明 ingest/reflection/retrieval 会让 break-even 相差数百 turn。StateMem 再增加 supersession/recompute 与高 ingest-call 成本。

**当前解释：** event boundary、write cadence、preservation、supersession 与 end-to-end economics 都是一等设计变量。

## 当前最强论文组合

- **ReFind + RippleMem**：raw search 何时足够、structure 何时通过 evidence completion 赢得复杂度。
- **StateMem + QUMem + QCR**：superseded history、retrieved evidence 与 current consumer state 的分离。
- **SkillEvo + SPADE + ERSkill + HyperSkill**：feedback、training-side experience、evolvable access 与 operational structure。
- **LycheeMemory V2 + FTA-Mem + Total Recall**：write granularity/cadence 与 lifecycle economics。
- **Practice Makes Unsafe + SkillJack**：persistent adaptation 的 lineage 与 revocation 风险。

没有论文达到 5/5。Coverage 仍窄，多数证据来自 benchmark，而不是持续运行的 deployment。

## 增强、减弱、未解决

**增强：** matched stage-specific control；raw evidence search；evidence-completing access；evolvable read program；consumer-state reconstruction；density-aware write；feedback-rich evolution；provenance/revocation；full lifecycle cost。

**需要观察的 early signal：** authority-aware commitment、supersession-aware resolution、retrieval 后 applicability/harm。当前每项只有一篇 accepted paper，不支撑趋势判断。

**减弱：** structured memory 本身作为贡献；one-shot flat retrieval；selected commitment label 作为 safe write 证据；retrieved record 直接等同 final consumer state；self-reflection 作为充分 evolution signal；final-context token 代表总成本。

**未解决：** computation 应放在哪里。ReFind 把工作移到 online；RippleMem/CABLE 在 write side 预计算结构；QUMem/StateMem 增加 query-time state processing；ERSkill/WER 支付 rollout/judge compute；FTA-Mem 在 write quality 与 cost 间折中。仍缺统一 objective 同时覆盖 construction、access latency、consumer-state quality 与 lifecycle risk。

## 什么证据会改变年度判断

如果 matched-budget raw search 关闭 evidence-completion gain；StateMem 的 supersession/recompute 在外部 acting workload 上失效；QUMem/QCR 的 consumer-state gain 在匹配 synthesis cost 后消失；MemTrap-style gate 在 mixed workload 中大量误拒有用 memory；或 governance 无法在长程 Agent 中保留 utility，当前解释应当减弱。

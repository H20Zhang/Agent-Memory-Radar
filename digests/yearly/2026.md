# Agent Memory Yearly — 2026

**Status:** rolling yearly compaction through 2026-08-13.  
**Radar coverage:** active curation starts in August and includes one backfilled paper published 2026-07-25; this is **not a full-year reconstruction**.

## Current yearly thesis

Within the narrow coverage available so far, agent memory is moving from a retrieval component toward a **selective state-control layer**. The durable question is not how much memory exists, but which representation/control state reaches which consumer, under what access, cost, and provenance contract.

A second correction is now strong enough to preserve: **neither structure nor compression is intrinsically valuable**. MESA shows several-but-not-all representations can beat both route-to-one and read-everything; MERIT and PGMem show plausible structure can add little unless a downstream operation uses it; The Sleeping Agent shows compression can preserve overall gist while selectively deleting a decision-critical field.

## Shifts visible in current coverage

### Flat retrieval → selective evidence interfaces

**V-Mem** exposes cross-modal same-round structure; **PMCoder** conditions retrieval on planner phase; **MESA** selects and composes a query-specific subset of memory structures.

**Current interpretation:** representation complexity is justified only when an access policy exploits it. “One store + one top-k” is too weak, but “read every view” is also not a scalable default.

### Relevance → admissibility and provenance-aware action

**AuthMem-Bench**, **MAFIA**, and **SkillJack** established authority/state-lineage failures. **MAP-Graph** makes hard read permission, recursive path trust, and action-risk sufficiency explicit control boundaries.

**Current interpretation:** provenance is becoming part of executable memory semantics. A relevant memory can still be the wrong state to read or act on.

### Query-token savings → lifecycle economics

**MemoryCPT** makes cost part of a learned objective. **Total Recall at What Cost?** shows why query context alone is insufficient: memory-system maintenance causes sustained cost break-even to range from immediate to beyond 400 turns depending on architecture/backbone/workload.

**Current interpretation:** memory economics must include ingest, consolidation/reflection, retrieval, and serving-stack behavior—not only the final payload.

### Reusable memory → consumer compatibility

**Agent Memory Distillation** transfers teacher experience through hierarchy and timing; **HyMeS** keeps motor competence in weights while memory strategy lives in code; a backfilled materials-science study treats validated fact/skill memory as a portable artifact across model backbones. **Agent Skills Can Be Harmful** supplies necessary counter-evidence: semantically relevant procedural guidance can still impose the wrong task behavior or cost.

**Current interpretation:** reusable memory has a consumer contract. Source quality, target capability, control granularity, and marginal execution effect determine whether transfer helps.

### Rich evidence state → smaller learned control state

**RoMeRL** remains the clearest warning against learning one utility variable per stored trajectory; **Scrub Jay** and **MemoryCPT** make utility/cost explicit at other lifecycle layers.

**Current interpretation:** long-lived systems may need rich evidence while keeping feedback-bearing policy state compact and semantically meaningful.

## Strongest papers in current coverage

- **MESA** — strongest evidence that multi-structure memory should be selectively composed rather than routed to one or fully unioned.
- **PMCoder** — bidirectional planner↔memory coupling with useful factorial evidence.
- **MAP-Graph** — provenance as operational access/action state rather than audit metadata.
- **Total Recall at What Cost?** — lifecycle serving economics and workload-dependent break-even.
- **RoMeRL / Agent Memory Distillation** — complementary results on bounded learned state and training-free experience transfer.

No work is currently rated **5/5**. The abstractions are getting sharper, but the radar still covers only a narrow slice of 2026 and much of the evidence is benchmark-bounded.

## Themes strengthening, weakening, or unresolved

**Strengthening:** selective structure-level access; controller/consumer alignment; provenance/admissibility; lifecycle cost; explicit memory-substrate choices.

**Weakening:** universal flat semantic memory; read-everything multi-memory; one learned utility per experience; source-local revocation; “smaller retrieved context means cheaper system”; structure as a contribution without matched causal evidence.

**Still unresolved:** how agents should *discover* the right memory control boundary rather than inherit human-designed views, planner phases, trust rules, or skill granularity.

## Durable trade-offs and open questions

- **Expressiveness vs control simplicity:** richer evidence should not imply equally rich learned routing state.
- **Utility vs governance:** valid access constraints can reduce apparent task utility, so aggregate success can reward the wrong memory policy.
- **Adaptivity vs total lifecycle cost:** reflection/learning can improve quality while delaying economic break-even.
- **Portability vs compatibility:** external memory can cross models/tasks, but mismatched consumers or procedural guidance can negate the benefit.

## What evidence would change this yearly view

The interpretation should weaken if matched flat/dynamic memories close current gaps once access/controller budgets are held constant; if provenance controls do not transfer beyond synthetic short workflows; if memory maintenance becomes negligible under realistic cheap/local models; or if memory compatibility across models/skills is predicted almost entirely by semantic relevance.

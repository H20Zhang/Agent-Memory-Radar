# Agent Memory Yearly — 2026

**Status:** rolling yearly compaction through 2026-08-12.  
**Radar coverage:** starts 2026-08-02; this is **not a full-year reconstruction** of 2026.

## Current yearly thesis

Within the narrow coverage available so far, agent memory is moving from a **retrieval-centric component** toward a **controlled state system** with explicit design choices over representation, access, lifecycle policy, feedback state, provenance, and security.

The strongest correction to the simple “better long-term retrieval” story is that these concerns interact: richer evidence may need specialized operators; learned memory policy may need a bounded control state; and state transformations create descendant artifacts whose authority and provenance must survive beyond the original record.

## Durable shifts visible in current coverage

### Flat semantic memory → typed evidence and structural access

**LeanMem** separates evidence by lifecycle semantics. **V-Mem** shows that for multimodal history, preserving shared conversational structure can matter more than direct cross-modal similarity: its same-round bridge supplies the dominant ablation gain.

**Current interpretation:** a memory representation should expose the relations that its access interface can actually exploit. “One store + one top-k operator” is increasingly a weak default assumption.

### More stored experience → not necessarily more learned control state

**MemoryCPT**, **Scrub Jay Memory**, and **RoMeRL** make memory policy an explicit optimization target, but RoMeRL exposes an important scaling issue: tying one learned utility variable to every accumulated trajectory dilutes finite feedback and increases observational reward contamination.

**Current interpretation:** long-lived agents may need **rich evidence state but reduced-order policy state**. The durable design question is what aspects of memory deserve learned control, not whether every record should carry an adaptive score.

### Semantic correctness → authority, integrity, and artifact lineage

**AuthMem-Bench** shows that consolidation can retain content while losing authority. **MAFIA** shows that persistent retrieval memory creates delayed state-poisoning attacks. **SkillJack** shows that experience-to-skill transformation can whitewash risk and create a descendant artifact that survives source deletion.

**Current interpretation:** memory correctness increasingly includes **who authorized state, how it entered the system, what was derived from it, and whether revocation propagates through descendants**.

### Early signal: retrieved procedure → compiled capability

**Muscle Memory** proposes compiling recurring user intent into executable specialist agents. This is conceptually compatible with the broader state-system thesis, but current evidence is synthetic and lacks a clean matched comparison with strong retrieval-based procedural memory.

This remains an **early signal**, not a durable yearly shift.

## Strongest papers in current coverage

- **RoMeRL** — reduced-order semantic utility state for runtime memory learning under sparse feedback.
- **V-Mem** — modality-routed, structure-aware access with a strong same-round ablation.
- **MemoryCPT** — end-to-end learned construction and read-time compression under a cost-quality objective.
- **LeanMem** — heterogeneous evidence types with different lifecycle semantics.
- **SkillJack** — provenance/revocation failure across experience-to-skill transformation.
- **AuthMem-Bench** — authority preservation as a memory correctness invariant.

**Scrub Jay Memory** and **MAFIA** remain important complementary design/security points. No work is currently rated **5/5**: the conceptual movement is meaningful, but coverage and external validity are still too limited for a field-shaping judgment.

## Themes strengthening, weakening, or still unresolved

**Strengthening:** typed lifecycle semantics; explicit learned/utility-aware memory policy; structural rather than purely similarity-based access; provenance and state integrity as memory invariants.

**Weakening:** one universal semantic store as the default abstraction; one independently learned utility per stored trajectory; source-local deletion as a sufficient revocation mechanism.

**Still unresolved:** learned versus deterministic memory transformation. Activity Frames is a credible counterpoint to “learn everything,” and the current evidence is consistent with a hybrid architecture where some state transformations remain deterministic and auditable.

## Durable trade-offs and open questions

- **Expressiveness vs control complexity:** richer evidence structures may improve reasoning while making routing, maintenance, and policy learning harder.
- **Adaptivity vs attribution:** outcome-optimized memory policies can work while assigning reward to the wrong memories; better causal credit may change which learned policies remain useful.
- **Efficiency vs provenance:** compression or skill extraction can reduce inference cost or repeated reasoning while losing trust metadata or creating hard-to-revoke descendants.
- **Specialized operators vs generality:** structure-aware access can outperform universal similarity on current benchmarks, but specialized interfaces may be brittle under task and modality drift.

## What evidence would change this yearly view

This interpretation should weaken if matched-budget flat-memory systems close the current gaps once provenance and stronger retrieval are included; if reduced-order policy states fail on open-ended tasks with many strategies and non-binary outcomes; if structure-aware multimodal access does not transfer to acting agents; or if provenance-aware transformations impose enough cost to erase their systems benefit.

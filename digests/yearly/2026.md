# Agent Memory Yearly — 2026

**Status:** rolling yearly compaction through 2026-08-12.  
**Radar coverage:** starts 2026-08-02; this is **not a full-year reconstruction** of 2026.

## Current yearly thesis

Within the narrow coverage available so far, agent memory is moving from a retrieval-centric component toward a **controlled state system whose representation, access operator, controller state, and trust semantics must be co-designed**.

A key correction emerged during the first backfill: the field should not equate “structured memory” with progress. The stronger evidence comes when structure corresponds to a real control boundary—same-round multimodal relations in V-Mem, planner phase in PMCoder, student decision granularity in AMD, or lifecycle semantics in LeanMem. MERIT supplies useful counter-evidence: plausible typing/polarity does not reliably beat a simpler dynamic memory.

## Shifts visible in current coverage

### Flat semantic memory → typed evidence and relation-aware access

**LeanMem** separates evidence by lifecycle semantics. **V-Mem** shows that preserving shared conversational structure can matter more than direct cross-modal similarity; its same-round bridge supplies the dominant ablation gain.

**Current interpretation:** a memory representation earns its complexity when its access interface can exploit a relation the flat baseline cannot.

### Passive memory subsystem → controller-coupled state

**PMCoder** makes planner state condition retrieval and lets memory statistics trigger replanning. **AMD** transfers teacher experience into task-, subtask-, and function-level memory delivered at different control points to a weaker student.

**Current interpretation:** memory is becoming part of the agent's control loop, not merely context storage. The consumer and timing of memory access may matter as much as the representation.

### More stored experience → not necessarily more learned control state

**MemoryCPT**, **Scrub Jay Memory**, and **RoMeRL** make memory policy an optimization target. RoMeRL exposes a scaling issue: tying one learned utility variable to every accumulated trajectory dilutes finite feedback and increases reward contamination.

**Current interpretation:** long-lived agents may need rich evidence state but reduced-order policy state.

### Semantic correctness → authority, integrity, and artifact lineage

**AuthMem-Bench** shows that consolidation can retain content while losing authority. **MAFIA** shows delayed persistent-state poisoning. **SkillJack** shows that experience→skill transformation can whitewash risk and create a descendant that survives source deletion.

**Current interpretation:** correctness includes who authorized state, how it entered memory, what was derived from it, and whether revocation propagates through descendants.

### Early signal: retrieved procedure → compiled capability

**Muscle Memory** compiles recurring user intent into executable specialists. Current evidence remains synthetic and lacks a strong matched retrieval-vs-compilation baseline, so this is still an early signal rather than a durable shift.

## Strongest papers in current coverage

- **PMCoder** — bidirectional planner↔memory coupling with a useful factorial interaction study.
- **RoMeRL** — reduced-order semantic utility state for runtime memory learning under sparse feedback.
- **Agent Memory Distillation** — training-free teacher→student capability transfer through hierarchy and retrieval timing.
- **V-Mem** — modality-routed, structure-aware access with a strong same-round ablation.
- **SkillJack** — provenance/revocation failure across experience→skill transformation.

No work is currently rated **5/5**. The conceptual movement is meaningful, but the radar covers only an early-August slice and external validity remains limited.

## Themes strengthening, weakening, or unresolved

**Strengthening:** controller-aligned access; bounded learned state; typed lifecycle semantics; provenance/state integrity.

**Weakening:** one universal semantic store; one utility per stored trajectory; source-local deletion as sufficient revocation; and the assumption that additional structure is intrinsically valuable.

**Still unresolved:** how to discover useful control boundaries automatically. PMCoder and AMD both benefit from human-legible granularities; open-ended agents may need learned state abstraction without inheriting RoMeRL's feedback-dilution problem.

## Durable trade-offs and open questions

- **Expressiveness vs control complexity:** richer evidence should not imply equally rich learned control.
- **Alignment vs generality:** hand-designed planner phases or hierarchy can make memory useful but may be brittle under domain drift.
- **Adaptivity vs attribution:** outcome-optimized memory can work while assigning credit to the wrong evidence.
- **Efficiency vs provenance:** compression or compilation can reduce cost while losing authority or creating descendants that are difficult to revoke.

## What evidence would change this yearly view

The interpretation should weaken if matched flat/dynamic memories close current gaps once controller state and budgets are held constant; if controller-coupled memory fails outside hand-structured domains; if reduced-order policy states fail on open-ended tasks; or if provenance-aware transformations impose enough overhead to erase their systems value.

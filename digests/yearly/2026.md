# Agent Memory Yearly — 2026

**Status:** rolling yearly compaction through 2026-08-14.  
**Radar coverage:** active curation starts in August and includes one backfilled paper published 2026-07-25; this is **not a full-year reconstruction**.

## Current yearly thesis

Within the narrow coverage available so far, agent memory is moving from a retrieval add-on toward a **multi-stage state interface**:

`archive/representation → access policy → selected evidence → consumer-facing reuse → lifecycle update/cost → provenance & revocation`.

The most important correction is methodological: **memory complexity should be credited only at the stage where a matched simpler alternative fails**. ReFind raises the baseline for representation claims by showing that raw chat plus stateful search can rival structured memory on precise refinding. QCR then shows the opposite failure mode: even correct retrieval of a rich trajectory can be insufficient when the actor needs target-bound rebinding. LycheeMemory V2 and Total Recall make write/update frequency and lifecycle cost explicit, while MAP-Graph, AuthMem, SkillJack, and Practice Makes Unsafe expand correctness into admissibility and descendant-state governance.

## Durable shifts visible in current coverage

### Precomputed representation → controllable evidence interface

V-Mem and MESA show that relations/views matter when access policy can exploit them. **ReFind** adds a strong negative control: on evidence-grounded chat memory, generated semantic structure is not required if the agent can iteratively search raw turns using session, local-context, temporal, and dedup controls.

**Current interpretation:** neither one flat top-k nor elaborate pre-built structure should be the default. The right baseline is a competent access policy over the least transformed evidence that still supports the task.

### Retrieved memory → adapted support for the current consumer

**QCR** holds retrieval and acting conditions fixed and shows that target-bound support from the same selected trajectory substantially outperforms direct raw-trace injection under binding shift.

**Current interpretation:** archival memory and actor-facing memory can be different objects. Retrieval quality and reuse quality need separate accounting.

### Per-turn memory work → explicit lifecycle scheduling and economics

**LycheeMemory V2** isolates consolidation granularity: semantic batching cuts construction frequency while fixed-window batching loses accuracy. **Total Recall** shows that total memory serving cost depends on internal ingest/reflection behavior, with break-even against full history varying by hundreds of turns.

**Current interpretation:** memory-system cost is an end-to-end lifecycle surface, and write/update cadence is a first-class design choice rather than a hidden implementation detail.

### Persistent experience → governed descendant state

**AuthMem-Bench** exposes authority loss, **SkillJack** exposes lineage/revocation failures across experience→skill transformation, **MAP-Graph** operationalizes read eligibility and path trust, and **Practice Makes Unsafe** traces unsafe skill authoring through later retrieval and clean-session harm.

**Current interpretation:** provenance must be executable state. Safe persistent adaptation requires observable, attributable, revocable transitions across every derived artifact.

### Rich evidence → bounded / consumer-compatible control state

**RoMeRL** remains the cleanest warning against one learned utility per stored trajectory. **Agent Memory Distillation**, **HyMeS**, and Agent Skills show that reusable memory must match the consumer's control granularity and execution semantics.

**Current interpretation:** rich evidence state does not imply equally rich learned policy state; externalized memory has a consumer contract.

## Strongest papers in current coverage

- **ReFind** — strongest negative control against mandatory semantic memory preprocessing.
- **QCR / Beyond Retrieval** — clearest separation of retrieval from post-retrieval reuse.
- **MESA / MAP-Graph** — strongest read-side evidence for selective structure composition and admissibility controls.
- **LycheeMemory V2 / Total Recall** — strongest evidence that write cadence and lifecycle economics matter independently of answer-context size.
- **Practice Makes Unsafe / SkillJack** — strongest persistent-adaptation lineage and revocation warning.

No work is currently rated **5/5**. The abstractions are becoming sharper, but coverage remains narrow and most evidence is benchmark-bounded rather than long-running deployment evidence.

## Themes strengthening, weakening, unresolved

**Strengthening:** matched stage-specific controls; query-time search over raw evidence; target-conditioned reuse; semantic consolidation scheduling; provenance/revocation as executable policy; lifecycle cost accounting.

**Weakening:** “structured memory” as a contribution by itself; one-shot flat retrieval as an adequate baseline; correct retrieval as sufficient for procedural memory; final-context tokens as a proxy for total cost; successful experience as automatically safe reusable state.

**Still unresolved:** where computation should live. ReFind moves intelligence online; Lychee amortizes write-side consolidation; QCR adds target-time support synthesis. We do not yet have a common optimization framework spanning construction cost, access latency, reuse success, and lifecycle risk.

## What evidence would change this yearly view

The interpretation should weaken if matched-budget simple retrieval closes the new access/reuse gaps; if semantic segment boundaries fail outside chat-style streams; if local/cheap memory models make write-side maintenance negligible; or if provenance/skill-governance controls cannot transfer to real long-running agents without substantial utility loss.

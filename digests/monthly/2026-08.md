# Agent Memory Monthly — 2026-08

**Status:** rolling month-to-date compaction through 2026-08-12. It will be finalized after the month closes.  
**Accepted papers so far:** 10

## The month so far

The early-August thesis has strengthened, but it has also become more specific: agent memory is broadening from a retrieval subsystem into a **controlled state layer**, and the interesting questions now sit at the boundaries between **representation, access, policy state, and trust lineage**.

The current map is not simply “more structure is better.” Three corrections matter. First, richer evidence may need specialized access operators rather than one universal similarity space. Second, a large memory pool does not imply a large learned control state. Third, provenance must survive transformations such as consolidation and skill compilation, not just storage.

## Design-space movement

### 1. One store / one similarity space → typed evidence + structural access

**LeanMem** argues that profile facts, evolving events, and source-grounded records deserve different lifecycle contracts. **V-Mem** adds the missing read-side evidence: in multimodal history, same-round structure and modality routing can matter more than direct cross-modal similarity.

The strongest V-Mem ablation is diagnostic: the large jump comes from **shared-round matching**, while the generated query anchor adds only a small increment afterward. That weakens the intuition that multimodal memory should primarily be solved by increasingly universal embeddings.

**Current movement:** represent evidence according to its lifecycle, then expose access operations that preserve the relations the representation was designed to encode.

### 2. Fixed heuristics → learned policy, but with bounded feedback-bearing state

**MemoryCPT** learns construction and query-time compression under an explicit cost-quality objective. **Scrub Jay Memory** gives individual memories their own temporal utility horizon. **RoMeRL** attacks a different bottleneck: if every new trajectory creates another learned utility variable, finite feedback is diluted and bundle-level rewards can reinforce irrelevant memories.

RoMeRL's four-coordinate formulation suggests a useful systems tension: **rich stored evidence may coexist with a much smaller learned control state**. This is more important than the specific number four; the general question is what semantic state actually deserves reinforcement feedback.

**Current movement:** memory management is becoming an optimizer, but the dimension and causal meaning of its control state matter as much as the learning algorithm.

### 3. Relevance correctness → provenance and lineage correctness

**AuthMem-Bench** shows that consolidation can preserve a statement while dropping who was authorized to make it. **MAFIA** shows that malicious state can be planted now and retrieved later. **SkillJack** adds a transformation boundary: poisoned experience can become a separately stored skill, become less detectable, and remain after the source record is deleted.

Together these papers shift the trust question from “is this retrieved memory relevant?” to **“what is the provenance and authority of this state, and what descendants were derived from it?”**

**Current movement:** provenance and revocation need to be transitive across summaries, consolidations, skills, and other derived artifacts.

### 4. Early signal: textual procedure → executable procedural memory

**Muscle Memory** proposes compiling recurring user intent into specialist mini-agents instead of repeatedly retrieving and reinterpreting textual preferences or procedures.

This is an **early signal, not a trend**. The representation change is interesting, but the evidence is synthetic and does not isolate compilation against a strong matched retrieval-based procedural-memory baseline.

## Strongest papers so far

1. **RoMeRL** — strongest correction to naive learned memory scaling: bounded semantic utility state instead of one learned variable per trajectory.
2. **V-Mem** — strongest access-interface result: structural same-round binding dominates its multimodal retrieval ablation.
3. **MemoryCPT** — strongest end-to-end cost × answer-quality optimization formulation.
4. **LeanMem** — strongest representation/lifecycle argument for heterogeneous evidence types.
5. **SkillJack** — strongest new lifecycle-security boundary: provenance and revocation must propagate into derived skills.

**Scrub Jay Memory**, **AuthMem-Bench**, and **MAFIA** remain important complementary anchors. **Activity Frames** and **Muscle Memory** are useful design points but currently have narrower evidence.

No paper is rated **5/5**. The month has several good abstractions and diagnostic experiments, but no result yet has evidence broad enough to call field-shaping.

## Persistent vs weakening themes

**Strengthening:** heterogeneous lifecycle semantics; explicit memory control policies; memory correctness beyond relevance; structure-aware access for multimodal state.

**Weakening:** the assumption that one flat semantic store plus a stronger embedding is the default answer; the assumption that every accumulated experience deserves its own learned utility; the assumption that deleting a source record revokes all of its behavioral influence.

**Not established:** that every memory transformation should be learned. Activity Frames remains a useful counterexample: deterministic compilation can improve auditability and construction cost. The likely frontier is a hybrid boundary between deterministic state transforms and learned policy.

## Unresolved trade-offs and hidden assumptions

- **Expressive memory vs compact control:** richer stores can preserve more structure while making routing and policy learning more complex. RoMeRL suggests the control state may need to stay much smaller than the evidence state.
- **Adaptivity vs causal attribution:** learned memory utility can optimize outcomes without knowing each memory's marginal causal contribution. Better reward assignment could materially change which policies survive.
- **Compression/capability vs trust lineage:** summarization, consolidation, and skill compilation can reduce cost or improve behavior while laundering provenance. Trust-preserving transformations may erase some of the apparent efficiency gains.
- **Specialized access vs generality:** V-Mem's modality routing and shared-round bridge are compelling in conversation QA, but it is unknown whether the same operators survive open-ended multimodal tool use.

## What would falsify the current view

The current thesis should weaken if a strong **flat memory** baseline with matched compute, provenance metadata, and answer model closes the gap to typed/structured systems; if RoMeRL-style bounded utility states fail outside tightly reusable tasks; if V-Mem's structural advantage disappears once multimodal agents act in environments rather than answer history questions; or if lineage-aware security controls prove too expensive to preserve useful memory transformations.

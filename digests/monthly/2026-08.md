# Agent Memory Monthly — 2026-08

**Status:** rolling month-to-date compaction through 2026-08-14. It will be finalized after the month closes.  
**Accepted August papers so far:** 25

## The month so far

The August map has moved beyond “memory is becoming a state-control layer.” A more falsifiable decomposition is emerging:

**archive/representation → access policy → selected evidence → consumer-facing reuse → lifecycle update/cost → provenance & revocation**.

The newest papers sharpen three boundaries that previous work blurred. **ReFind** shows that elaborate semantic preprocessing must beat a competent stateful interface over the raw record, not a weak one-shot retriever. **QCR** shows that correct retrieval still leaves a post-retrieval reuse problem: the same selected trajectory is much more useful when rewritten around current bindings and verification. **LycheeMemory V2** shows that the write side has its own control variable—the granularity/frequency of expensive consolidation. **Practice Makes Unsafe** then shows why persistent adaptation needs governance across every transformation and reuse stage.

The resulting correction is stricter than “more structure is not always better”: **every memory transformation must identify the downstream decision it improves, compared with a matched simpler interface, and account for the cost/risk it introduces elsewhere in the lifecycle.**

## Design-space movement

### 1. Pre-build semantic memory → preserve raw evidence until the question is known

Earlier August work mostly asked which representation or access operator should be used. V-Mem showed same-round structure can matter; MESA showed several views can beat both route-to-one and read-everything.

**ReFind** supplies the strongest counterweight so far. It creates no learned/LLM-generated semantic memory: raw timestamped turns are indexed with BM25, and a ReAct retriever controls session-aware rank fusion, ±2-turn expansion, time filtering, and seen-session deduplication.

The matched control matters more than the headline leaderboard. On fixed LongMemEval-S/M subsets, full ReFind is **93.2/89.3**, versus **78.7/82.2** for generic-agentic BM25 with the same controller but no chat-native controls, and **84.7/68.9** for one search. Across six MemoryAgentBench tasks its 58.2 macro-average exceeds HippoRAG 2 at 53.2.

**Current movement:** precomputed semantic structure is no longer the default control. For precise archival refinding, question-directed online computation over raw evidence can be competitive or stronger; future structure claims need this baseline.

### 2. Retrieval quality → post-retrieval reuse quality

PMCoder already showed that controller state and memory access should interact. **QCR** isolates a later boundary: what happens *after* a useful trajectory has been retrieved and selected.

With retrieval, selected source memory, actor, target state, decoding, and tool budget held fixed, QCR converts the selected trajectory into a target-bound support object: reusable workflow, bindings to re-obtain, applicability conditions, and a verification guardrail. Across 2,391 WebArena/WorkArena/AppWorld targets it reaches **62.3% Success**, **+10.7pp** over direct Full Trajectory while using **48.9% fewer online tokens**. Under large binding shifts, stale source-value errors fall **46.9%→10.9%** and correct rebinding rises **31.7%→77.8%**.

**Current movement:** storage, retrieval, and reuse are separate system stages. A full-fidelity trajectory may be the right archival object but the wrong actor-facing memory.

### 3. Memory construction cost → consolidation-frequency control

Total Recall showed that memory economics are lifecycle-wide: ingest/reflection behavior can move break-even by hundreds of turns. **LycheeMemory V2** attacks one concrete source of that cost—the frequency of LLM memory construction.

On LoCoMo, semantic segment-level consolidation reaches **89.22** with **204.1K** construction tokens. Eager per-turn consolidation uses **849.9K** (+316%) yet falls to 81.88; fixed-window batching is cheap (174.7K) but falls to 82.40. This separates the two mechanisms cleanly: **batching reduces write cost; semantic boundaries preserve accuracy**.

**Current movement:** memory-update cadence/granularity is becoming a first-class control variable, orthogonal to representation and retrieval.

### 4. Persistent adaptation → governed state transitions

SkillJack showed experience can be transformed into descendant skills whose risk and lifetime outlive the source. Agent Skills Can Be Harmful showed that even relevant procedural guidance can impose the wrong execution procedure.

**Practice Makes Unsafe** adds a lifecycle experiment: successful but unsafe experience is repeatedly evolved into persistent skills, then probed in clean sessions. Across 25 agent-method configurations, all 21 evolved settings author unsafe artifacts and 15 produce fresh-session harm. Three malicious tasks raise carryover ASR **16.0%→35.3%**. SafeEvolve lowers unsafe retrieval **35.33%→8.67%** and carryover ASR **21.33%→4.00%** averaged over two representative evolution methods.

**Current movement:** persistent adaptation needs observable, attributable, revocable transitions across `experience → skill → retrieval → execution → outcome`, not just output filtering.

## Strongest papers so far

1. **ReFind** — strongest negative control against mandatory semantic memory construction; raises the baseline for every future “structured memory” paper.
2. **QCR / Beyond Retrieval** — cleanest evidence that post-retrieval reuse is a distinct bottleneck once source bindings and target state diverge.
3. **MESA / MAP-Graph** — complementary evidence that read-side policy selects both *which representation* and *whether evidence is admissible*.
4. **LycheeMemory V2 / Total Recall** — strongest current write-side + lifecycle-cost evidence; construction frequency and serving economics cannot be inferred from answer-context size.
5. **Practice Makes Unsafe / SkillJack** — strongest current state-lineage warning for self-evolving procedural memory.

No paper is rated **5/5**. The new causal controls are sharper than earlier August work, but external validity is still concentrated in chat QA, benchmark web agents, and controlled skill-evolution environments.

## Persistent vs weakening themes

**Strengthening:** query-time controllable access; consumer-facing memory adaptation; consolidation granularity as policy; provenance/revocation across derived state; matched simpler controls.

**Weakening:** semantic preprocessing as an unquestioned default; one-shot top-k as a meaningful flat baseline; “retrieved the right item” as sufficient for procedural reuse; “fewer final-context tokens” as evidence of cheaper memory; successful experience as automatically safe reusable policy.

**Still unresolved:** which memory work should happen offline versus online. ReFind deliberately spends more at query time to avoid semantic preprocessing; Lychee amortizes write-side work across semantic segments; QCR adds a target-time synthesis step after retrieval. The field does not yet have a common objective over construction cost, search latency, reuse quality, and downstream risk.

## Tensions and hidden assumptions

- **Offline structure vs online search:** ReFind challenges preprocessing, but its full search loop is materially more expensive than simpler query-time controls. A low-latency product may still prefer precomputation.
- **Archival fidelity vs consumer safety:** QCR argues for preserving full trajectories but delivering target-bound support. That transformation can itself hallucinate or omit constraints unless provenance/verification remain explicit.
- **Adaptive consolidation vs nonstationarity:** Lychee's semantic boundaries look clean in conversational QA; real agents may produce abrupt tool events, conflicting updates, and asynchronous state that do not align with embedding cohesion.
- **Self-improvement vs governance:** Practice Makes Unsafe shows safety layers can reduce propagation, but persistent risk evidence and retirement rules may also suppress useful reusable procedures.

## What would falsify the current view

The current thesis should weaken if: a simple one-shot retriever closes ReFind once online token/latency budgets are strictly matched; direct raw trajectories match QCR under naturally recurring tasks without constructed binding shift; fixed-window consolidation matches semantic segmentation across diverse streaming agents; or safety-aware skill lifecycle controls fail to reduce real-world carryover harm without substantial utility loss.

# Agent Memory Monthly — 2026-08

**Status:** rolling month-to-date compaction through 2026-08-20. It will be finalized after the month closes.  
**Accepted August papers so far:** 40

## The month so far

The strongest August correction is methodological: **credit complexity only at the stage where a matched simpler alternative fails**. The working map is now:

`archive / representation → state localization → access / expansion / admission → consumer-facing state → update / evolution → governance / cost / provenance`

The Aug 18 papers sharpen three boundaries. **ArborMem** inserts state localization before retrieval; **CABLE** makes graph links explicitly complementary to a host retriever. **D²ACCI** and **Explicit State Elicitation Is Not Enough** push evaluation from endpoint score toward causal promotion evidence. **WER** and **TRUSS** move procedural evolution from generic self-reflection toward execution-grounded writer learning and runtime certification.

## Design-space movement

### 1. “Retrieval” → state localization + direct reach + complementary reach

**ReFind** remains the raw-state control: one-shot top-k is not a credible baseline for structured memory when an agent can search raw timestamped history iteratively.

**ArborMem** asks an earlier question. Before retrieving relevant memories, identify which prior interaction state the current turn resumes. On a fixed LongMemEval subset, removing localization drops the 30B setting **82→70**, but only **48→46** for 4B; atomic-fact retrieval is also load-bearing. The result supports state localization as a real boundary, not the forest representation alone.

**CABLE** asks a later question: if a host retriever already reaches semantic neighbors, which links actually extend its reach? It removes the direct semantic neighborhood from antecedent candidates before verification, then expands one hop under the same final evidence-count budget. With A-MEM, LoCoMo Qwen3.5 rises **71.23→74.81** and MA-LongMemEval Qwen **59.33→65.33**. The negative temporal-reasoning slice (**−1.33/−2.67pp**) prevents a universal “more reach is better” conclusion.

**RippleMem** remains the complementary read-time design point: first-hop memories become anchors for missing-evidence search. **TRACE-Memory** adds admission/abstention after retrieval.

**Current movement:** evaluate `active-state localization → seed retrieval → complementary expansion/recollection → admission` as separate operators rather than one retrieval score.

### 2. Endpoint metrics → promotion protocols and causal intermediate-state audits

**D²ACCI** turns memory-system iteration into a gated promotion problem. Supplement extraction (**+2.71pp, p=.0009**), session retrieval (**+3.67pp, p=.0026**), and Forget Guard (**+1.92pp, p=.0030**) clear paired tests; BM25/RRF remains feature-flagged because LoCoMo/LongMemEval effects are statistically null. Enriched stage traces also improve root-cause agreement (**κ=.571/.619 vs .258/.272** result-only).

**Explicit State Elicitation Is Not Enough** supplies the negative control. On a frozen 160-example counterfactual set, Llama improves **44.0→53.1** from taxonomy definitions but explicit state output is only **44.6**; GPT-OSS shows a marginal non-significant **54.8→58.1**. A richer semantic-evidence follow-up can even hurt. Interpretability/sensitivity is therefore not evidence that the intermediate state causes better policy decisions.

**Demystifying Agent Skills**, **AuthMem-Bench**, **Total Recall**, and **Practice Makes Unsafe** support the same broader shift: representation, retrieval, invocation, cost, authority, and descendant harm need separate attribution.

**Current movement:** a memory feature should earn promotion through **paired effect + protected-slice non-regression + trace localizability**, not because its intermediate representation is readable or its aggregate score rises.

### 3. Retrieved evidence → consumer-compatible state

**QCR** holds the selected trajectory fixed and shows that target-conditioned reuse is a distinct post-retrieval bottleneck: **62.3% success, +10.7pp over Full Trajectory, −48.9% online tokens**, with large reductions in stale-binding errors.

**QUMem** reaches the same boundary from personalization. Its largest PersonaMem ablation is query-time user-state reconstruction (**61.02→54.51** without reconstruction), larger than removing episode construction or typed decomposition.

The explicit-state audit is an important correction to both: **not every explicit post-retrieval state is useful**. Reconstruction must be validated by matched downstream behavior, not by structural interpretability.

**Current movement:** archive, retrieved evidence, intermediate state, and actor-facing state are different objects with different causal burdens.

### 4. Self-improvement → execution-grounded state transitions

**SkillEvo** showed that richer multi-turn feedback exposes defects after single-turn feedback saturates. **WER** moves one step further by training the skill-writer policy from repeated execution outcomes. Under the same Qwen3-4B refinement workflow, training raises BFCL **67.28→76.63 (+9.35)** and tau2 **40.43→50.72 (+10.29)**; another refinement step regresses **76.63→75.33**.

**TRUSS** uses execution differently: not primarily to train the writer, but to certify/refine candidate procedural artifacts. On matched SkillInject artifacts, detection moves from LLM checker **44.64% precision / 19.05% recall** to static **81.55/94.05** to full TRUSS **100/100**; attack success falls under both evaluated target models. The package effect remains partially confounded and safe-task completion is model-dependent.

**ERSkill** evolves the read policy; **HyperSkill** makes relational structure operational in retrieval/maintenance. These systems now occupy different adaptive-state locations rather than one “self-evolving memory” category.

**Current movement:** distinguish **feedback generator → artifact edit → writer learning → runtime certification → read-policy evolution → governance**.

### 5. Write granularity and lifecycle economics remain unresolved

**LycheeMemory V2** shows that consolidation cadence matters. **FTA-Mem** shows the preferred persistent unit can change with evidence density: on ES-MemEval, session **31.76 F1 / 1.58M tokens**, turn-pair **37.06 / 6.40M**, FTA **38.71 / 4.99M**; on denser LoCoMo, turn-pair is slightly more accurate but roughly doubles construction tokens.

**Total Recall** prevents a false systems conclusion: a dedicated memory layer is not automatically cheaper than retaining history. CABLE and WER add the same accounting pressure from different sides—write-time link construction and rollout-based writer training can improve online behavior while moving cost elsewhere.

**Current movement:** construction, training, retrieval, reconstruction, maintenance, reacquisition, and governance need one lifecycle objective rather than separate “offline” and “online” victories.

## Strongest papers so far

1. **ReFind + ArborMem + CABLE + RippleMem** — strongest current decomposition of the read path from raw-state control through state localization and complementary evidence reach.
2. **D²ACCI + Explicit State Elicitation + Demystifying Agent Skills** — strongest causal-evaluation correction: interpretable states and endpoint scores are insufficient without matched effects and stage attribution.
3. **QUMem + QCR** — strongest evidence that retrieved evidence and consumer-facing state are different stages.
4. **SkillEvo + WER + TRUSS + ERSkill** — strongest evidence that procedural evolution has multiple adaptive-state locations and needs execution-grounded feedback/governance.
5. **LycheeMemory V2 + FTA-Mem + Total Recall + AuthMem-Bench/SkillJack** — strongest lifecycle reminder: write policy, cost, authority, and descendant state remain first-class constraints.

No paper is rated **5/5**. External validity is still concentrated in conversational QA, personalized generation, benchmark web/tool agents, cloud-support skills, and controlled evolution environments.

## Persistent vs weakening themes

**Strengthening:** competent raw-state controls; explicit state localization; retriever-complementary relation construction; evidence-completion operators; admission/abstention; consumer-state reconstruction; paired promotion protocols; execution-grounded skill-writer learning; runtime skill certification; full lifecycle cost/provenance accounting.

**Weakening:** one-shot top-k as a flat-memory baseline; graph structure without a reachability/operator claim; “retrieval” as one causal stage; explicit intermediate state as evidence of faithful mechanism; self-reflection as sufficient evolution supervision; endpoint success as sufficient deployment evidence.

## Tensions and hidden assumptions

- **Precompute vs online recovery:** ArborMem/CABLE spend construction/organization work to reduce ambiguity or extend reach; ReFind shifts work to query time. The field still lacks a shared crossover objective.
- **More reach vs more distraction:** CABLE improves distributed-evidence slices but harms temporal reasoning; expansion policies need precision/admission controls, not only recall.
- **Explicit state vs causal state:** QUMem/QCR show useful reconstruction/rebinding; the controlled audit shows that merely emitting a state label can add nothing. The difference is matched downstream effect.
- **Execution feedback vs executable verification:** WER learns the writer from outcome rewards; TRUSS uses execution traces to gate/refine artifacts. Both require environments whose feedback is trustworthy enough to supervise persistence.

## What would falsify the current view

The thesis should weaken if state localization adds little outside synthetic/interleaved conversation tasks; matched online search closes CABLE/RippleMem gains once write+query cost is equalized; explicit state representations reliably improve downstream actions under stronger counterfactual controls; D²ACCI-style gates fail to transfer beyond one instrumented stack; or WER/TRUSS gains disappear when verifier quality, target model, and rollout cost are matched in real evolving skill libraries.

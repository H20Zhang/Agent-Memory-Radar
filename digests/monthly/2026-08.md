# Agent Memory Monthly — 2026-08

**Status:** rolling month-to-date compaction through 2026-08-13. It will be finalized after the month closes.  
**Accepted August papers so far:** 21

## The month so far

The early-August thesis has become more discriminating: **agent memory is turning into a selective state-control layer, and every extra structure or transformation must justify itself at the boundary where evidence is consumed.** The newest papers widen that boundary beyond relevance: MESA chooses *which representation* to expose, MAP-Graph decides *whether derived evidence is admissible*, Total Recall asks *when the lifecycle economically pays for itself*, and Agent Skills shows that a semantically relevant procedural memory can still impose the wrong execution trajectory.

This corrects two simplistic narratives at once. “More structured memory is better” fails under MERIT and PGMem's ablations; “smaller retrieved context is cheaper” fails under Total Recall. The useful question is increasingly **what decision does this memory representation/control policy change, compared with a matched simpler alternative?**

## Design-space movement

### 1. Fixed memory interface → query-adaptive evidence composition

**V-Mem** showed that preserving same-round structure can beat universal cross-modal similarity. **PMCoder** made planner phase condition retrieval. **MESA** generalizes the read-side problem: the optimal query often needs several memory views, but not all of them.

The diagnostic MESA comparison is unusually clean: route-to-one is **57.0%**, all five structures **63.7% / 18.7k evidence tokens**, and adaptive selection **65.1% / 11.0k** using 2.8 structures on average. A coarse domain-conditioned selector already reaches 64.4%, so the evidence supports **adaptive composition** more strongly than it supports a sophisticated learned selector specifically.

**Current movement:** access policy is becoming a first-class system component over representation choices, not merely top-k over stored items.

### 2. Semantic relevance → admissibility, trust, and action sufficiency

**AuthMem-Bench**, **MAFIA**, and **SkillJack** established authority, persistent-state integrity, and descendant lineage as memory-correctness issues. **MAP-Graph** turns that diagnosis into an operational interface: hard read eligibility, recursive path trust, and action-risk gating are separate decisions.

Its most important ablation is not the headline score. Removing the permission filter slightly improves aggregate utility while conditional unauthorized access becomes **100%**. That exposes a general benchmark failure: endpoint success can hide a violated memory-access boundary.

**Current movement:** provenance is shifting from audit metadata to executable memory policy state.

### 3. Memory efficiency → lifecycle economics, not answer-context size

**MemoryCPT** already optimized answer quality against query-time cost. **Total Recall at What Cost?** adds a system-level correction: maintenance behavior can dominate economics even when retrieved answer context is small.

Across its measured grid, sustained break-even against full history ranges from **0–86 turns for Mastra OM, 0–342 for Mem0, and 60–never for Hindsight**. A simple depth/message-size model misses memory-system cost by **18–69%** because internal extraction/reflection behavior matters.

**Current movement:** cost claims need a workload-dependent break-even surface over the whole memory lifecycle, not a token-saving headline.

### 4. Reusable procedural memory → compatibility and marginal-effect control

**AMD** shows teacher experience can transfer capability when memory granularity/timing matches the student. **HyMeS** puts inspectable task-state strategy in code while motor skills remain in VLA weights. **Agent Skills Can Be Harmful** supplies the counterweight: relevant reusable skills can still reduce quality or inflate cost by changing required implementation/verification behavior.

The study confirms 307 matched skill-related regressions; efficiency cases are dominated by **Excessive Procedure (114/182)** rather than context bloat alone. A separately backfilled July paper on materials-science agents also shows cross-model memory transfer is asymmetric: stronger-source experience can help a weaker consumer, while weaker-source memory can be neutral or harmful.

**Current movement:** portable memory needs a compatibility/admission policy; “retrieved because relevant” is not enough.

### Early signal: compression needs field-level preservation contracts

**The Sleeping Agent** shows a generic gist prompt preserving events/entities while deleting temporal expressions; explicit temporal protection raises preservation **3.05%→62.39%** and recovers **+0.314** temporal-question accuracy. This is a useful diagnostic but remains one compression pipeline on LoCoMo, so it is an **early signal**, not yet a general trend.

## Strongest papers so far

1. **MESA** — strongest new evidence that multi-structure memory is a selective-composition problem rather than route-to-one or read-everything.
2. **PMCoder** — strongest controller↔memory coupling result; planner state affects retrieval and memory state can trigger replanning.
3. **MAP-Graph** — strongest operational provenance decomposition: read eligibility, graded ancestry trust, and action sufficiency are different control boundaries.
4. **Total Recall at What Cost?** — strongest correction to naive memory-economics claims; break-even is architecture/workload dependent.
5. **Agent Memory Distillation / HyMeS** — complementary evidence that memory substrate and consumer granularity determine whether reusable experience transfers.

**RoMeRL, V-Mem, SkillJack, AuthMem-Bench, MemoryCPT, LeanMem, and Scrub Jay** remain important complementary anchors. **MERIT, PGMem, and The Sleeping Agent** are useful negative/diagnostic results that prevent overgeneralizing “more structure” or “more compression.”

No paper is rated **5/5**. The month contains several sharp mechanisms and matched ablations, but external validity is still concentrated in bounded benchmarks and synthetic/controlled workloads.

## Persistent vs weakening themes

**Strengthening:** selective access/composition; explicit controller/consumer alignment; provenance as operational control; lifecycle cost as an evaluation axis; memory compatibility across models/skills.

**Weakening:** one flat store + stronger embedding as the universal answer; read-everything multi-memory; one utility per stored trajectory; “structured” as a contribution by itself; and “retrieval means cheaper serving.”

**Still unresolved:** where adaptive memory state should live—learned scores, explicit symbolic state, executable code, or external artifacts—and how to change substrate without losing provenance or consumer compatibility.

## Unresolved trade-offs and hidden assumptions

- **Expressive evidence vs simple access policy:** MESA beats all-structure, but a coarse domain selector is already close; many benchmarks may expose predictable routing shortcuts.
- **Governance vs utility:** MAP-Graph shows hard access constraints can lower apparent utility; evaluation that rewards only task success may systematically prefer invalid reads.
- **Adaptivity vs lifecycle cost:** learned/reflection-heavy memory can improve quality while moving economic break-even far into the future.
- **Portability vs compatibility:** AMD, HyMeS, materials memory, and Agent Skills all imply that reusable memory has a consumer contract; relevance alone cannot predict benefit.

## What would falsify the current view

The current thesis should weaken if a matched flat/dynamic memory with simple metadata closes MESA/PMCoder/MAP-Graph gaps; if provenance-aware controls lose their advantage in genuinely long-running workflows; if internal memory maintenance becomes negligible under realistic local/cheap models; or if skill/cross-model compatibility can be predicted almost entirely by semantic relevance.

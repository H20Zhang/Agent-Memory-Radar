## The month so far

The early-August map has moved beyond “memory is becoming a controlled state layer.” The more discriminating hypothesis is now: **memory value comes from aligning representation, access, and policy state with the decision boundary that consumes the evidence**.

That explains why several structured systems work—and why structure sometimes does not. V-Mem's same-round bridge exposes a relation that cross-modal similarity misses; PMCoder couples retrieval to planner phase; AMD aligns task/subtask/function memory to a weaker student's control granularity. In contrast, MERIT's extra failure typing and polarity do not reliably beat untyped dynamic retrieval.

## Design-space movement

### 1. One store / one similarity space → typed evidence + relation-aware access

**LeanMem** argues that profile facts, evolving events, and source-grounded records need different lifecycle contracts. **V-Mem** supplies read-side evidence: in multimodal history, same-round structure and modality routing can matter more than direct cross-modal similarity.

The V-Mem ablation remains diagnostic: most of the gain comes from **shared-round matching**, not the generated query anchor.

**Current movement:** preserve relations that a later access operator can exploit; do not collapse every evidence type into one universal semantic store.

### 2. Memory subsystem → memory/controller co-design

**PMCoder** makes the coupling explicit: planner phase conditions memory retrieval, while memory trajectory statistics can trigger stuck detection and replanning. Its factorial study reports more benefit from the combined system than from plan-only or memory-only variants.

**AMD** adds a cross-model version: teacher experience becomes useful to a smaller student when it is decomposed into workflow, subtask, and function memories and delivered proactively or reactively at the corresponding decision point.

**Current movement:** a memory interface is increasingly defined by *who consumes it and when*, not only by what is stored.

### 3. Fixed heuristics → learned policy, but with bounded feedback-bearing state

**MemoryCPT** learns construction and read-time compression under an explicit cost-quality objective. **Scrub Jay Memory** gives memories individual temporal utility horizons. **RoMeRL** shows a scaling failure of trajectory-indexed utility: as experience grows, finite feedback is diluted and bundle-level rewards can reinforce irrelevant memories.

**Current movement:** memory management is becoming an optimizer, but the dimension and causal semantics of the optimized control state matter as much as the learning algorithm.

### 4. Relevance correctness → provenance and lineage correctness

**AuthMem-Bench** shows that consolidation can preserve content while losing authority. **MAFIA** demonstrates persistent state poisoning through ordinary interaction. **SkillJack** shows that experience→skill transformation can create a descendant artifact that is less inspectable and survives source deletion.

**Current movement:** provenance and revocation need to be transitive across summaries, consolidations, skills, and other derived artifacts.

### Early signal: textual procedure → executable capability

**Muscle Memory** compiles recurring intent into specialist mini-agents rather than repeatedly retrieving textual procedure. This remains an **early signal, not a trend**: evidence is synthetic and does not isolate compilation against a strong matched retrieval-based procedural-memory baseline.

## Strongest papers so far

1. **PMCoder** — strongest controller-coupling evidence; its planner×memory interaction is a reusable systems result if it transfers beyond coding.
2. **RoMeRL** — strongest correction to naive learned-memory scaling: bound semantic utility state instead of learning one control variable per trajectory.
3. **Agent Memory Distillation** — strongest new memory-transfer result: structured teacher experience can improve 4B–8B tool agents without parameter updates.
4. **V-Mem** — strongest access-interface ablation: structural same-round binding dominates the multimodal retrieval improvement.
5. **SkillJack** — strongest lifecycle-security boundary: trust and revocation must propagate into derived skills.

**MemoryCPT, LeanMem, Scrub Jay, AuthMem-Bench, and MAFIA** remain important complementary anchors. **MERIT** is a useful negative result because it shows that additional structure is not automatically load-bearing.

No paper is rated **5/5**. The current evidence contains good abstractions and several diagnostic ablations, but not yet broad enough external validity for a field-shaping judgment.

## Persistent vs weakening themes

**Strengthening:** representation/access alignment; explicit memory/controller coupling; bounded learned memory state; correctness beyond relevance.

**Weakening:** “one flat store + stronger embedding” as the universal default; one learned utility per experience; and, importantly, the newer assumption that **more structured memory is automatically better**.

**Still unresolved:** learned versus deterministic transformation. Activity Frames remains a useful counterexample to “learn everything,” while PMCoder shows that deterministic controller structure can make a learned agent's memory interface more effective.

## Unresolved trade-offs and hidden assumptions

- **Expressive evidence vs compact control:** richer evidence structures can improve access while making learned control and routing harder; RoMeRL suggests these states should not scale together.
- **Controller alignment vs generality:** PMCoder benefits from explicit repair phases and AMD from a known task/subtask/function hierarchy; open-ended agents may not expose equally clean control boundaries.
- **Structure vs matched simple baselines:** MERIT shows that a plausible taxonomy can fail to beat untyped retrieval. Every new memory type should earn its complexity through a matched ablation.
- **Efficiency vs provenance:** compression and skill extraction can improve cost/capability while changing authority or creating hard-to-revoke descendants.

## What would falsify the current view

The current thesis should weaken if matched-budget flat/dynamic memory closes the gap once controller state and metadata are held constant; if PMCoder-style bidirectional coupling fails when phase structure is not hand-designed; if AMD loses most of its advantage under distribution-shifted teacher experience; or if provenance-aware transformations erase the efficiency gains that motivate them.

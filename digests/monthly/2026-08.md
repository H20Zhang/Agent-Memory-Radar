# Agent Memory Monthly — 2026-08

**Status:** rolling month-to-date compaction through 2026-08-10. It will be finalized after the month closes.  
**Accepted papers so far:** 6

## The month so far

The strongest early-August signal is that agent memory is broadening from a **retrieval subsystem** into a **state-management layer**. The most interesting work is not asking only how to retrieve old context; it is asking how memories should be typed, written, compressed, forgotten, trusted, and optimized over time.

## Design-space movement

### From one memory store → heterogeneous memory lifecycles

LeanMem and Activity Frames point toward different preprocessing and lifecycle semantics for different evidence types. This weakens the common “everything becomes chunks in one semantic store” abstraction.

### From fixed heuristics → explicit memory policies

MemoryCPT and Scrub Jay Memory make policy itself the object of optimization: what to retain, compress, or forget should depend on downstream utility and cost. If this direction holds, memory systems will increasingly resemble optimizers over state rather than passive databases of historical text.

### From relevance correctness → state correctness

MAFIA and AuthMem-Bench show that retrieving the right-looking fact is insufficient. A memory system can be semantically useful while being unsafe because the state was poisoned, stripped of authority, or detached from provenance.

## Most important papers so far

1. **MemoryCPT** — strongest early formulation of end-to-end memory cost/performance optimization.
2. **LeanMem** — strongest signal that heterogeneous evidence needs heterogeneous lifecycle semantics.
3. **Scrub Jay Episodic Memory** — useful abstraction for per-memory temporal utility and forgetting.
4. **MAFIA** — makes persistent-state poisoning concrete as a memory-specific attack surface.
5. **AuthMem-Bench** — exposes authority preservation as a memory invariant rather than optional metadata.

No paper is rated 5/5 yet. That is deliberate: the conceptual signals are interesting, but the month currently lacks evidence strong enough to call any one result field-shaping.

## Emerging research thesis

A useful way to model the current direction is:

> **Agent memory is becoming a queryable, mutable, policy-controlled state system whose correctness includes utility, cost, provenance, and safety.**

This framing is more predictive than treating agent memory as “RAG over conversation history.” It also suggests that future systems may need explicit schemas, lifecycle operators, optimization objectives, and integrity constraints.

## What is still missing

- **Unified lifecycle evaluation:** write/update/forget/retrieve are usually evaluated separately, so cross-stage regressions are easy to hide.
- **Cost × accuracy × safety trade-offs:** MemoryCPT addresses cost/quality, while security papers address trust, but these dimensions are not jointly optimized.
- **Multimodal and structured-memory evidence:** the current curated set is still dominated by textual/structured settings; it is too early to infer that the same abstractions transfer cleanly to long-horizon multimodal agents.

## What would change this monthly view

The current thesis should be revised if later-August work shows that gains still come mostly from better semantic retrieval rather than lifecycle/state abstractions, or if strong evaluations demonstrate that a simple unified memory representation matches heterogeneous designs at materially lower complexity.

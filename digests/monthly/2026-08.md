## Month thesis

August did not establish a winning memory architecture. The stronger update is a causal one: **persistent state should receive credit only after a matched simpler archive fails under the same qualification policy, actor interface, and lifecycle budget.** Across the native-v2 acceptances, the repeated bottleneck is the policy that decides which state is current, applicable, verified, exposed, and actually reusable by a later actor—not the mere existence of a richer stored representation.

The native-v2 cutover began on 2026-08-20. Earlier August papers with unknown historical Radar acceptance times remain useful context, but they are not counted as August acceptance evidence in this closed digest.

## Three design-space movements

### 1. `retrieve → consume` became `candidate state → qualify → consume`

**StateMem** separates retrieved history from current operative state: on its DeepSeek setting, extraction-only is **0.174**, adding supersession reaches **0.298**, and full StateMem reaches **0.363**; dependency propagation is not universally helpful because removing it reaches **0.373**. **When Stale Constraints Go Unchecked** gives the cleaner causal intervention: with the same `k=2` verification budget, reallocating one existing slot to the critical provenance path improves current-record-consistent decisions by **61.3–74.0 percentage points** in superseded worlds, while valid-world outcomes move by only **0–2.0 points**.

**MemTrapBench**, **Remember, Verify, or Ask?**, **Utility Under Attack**, and **MemGuard** expose adjacent failure surfaces: relevant history can still be inapplicable, authority/scope decisions can precede commitment, trust weighting can trade safety against useful low-trust evidence, and verifier outputs only become governed state if they persist beyond admission. The common implication is narrower than “verification helps”: memory quality depends on an explicit **qualification policy before consumer exposure**.

### 2. A procedural memory is increasingly a policy over skills, not just a skill library

**SkillGate** makes skill exposure a learned decision; **Optimal Skill Selection** shows that skill utility can be set-valued rather than independently relevant; **Break It Down, Pass It On** shows that write granularity can reverse the average value of procedural memory. **Recuris** provides the strongest control: on tau2-Retail, Base is **58.1%**, working-memory-only **82.0%**, same-library model-controlled invocation **65.6%**, and full Recuris **83.6%**. Holding the ten-skill library fixed makes current-state tracking and invocation policy more explanatory than library availability. Its Terminal-Bench adaptation claim also collapses under the closest attempt-budget control: **58.6%→60.9%, p=.774**.

**HiPS** extends the same idea to the memory-management policy itself, splitting persistent rules into shared and persona-specific state. Its strongest evidence comes from matched ablations and cross-model rule transfer, not from the heterogeneous headline leaderboard. The research unit is therefore shifting from “which artifact should be stored?” toward **write unit × state estimator × set selector × invocation/update policy**.

### 3. Architecture claims now need executable behavior, a strong raw/verbatim control, and full lifecycle cost

**DreamBench-SWE** is the clearest negative control. Persistent state matters for later executable patches—**21/180** with no external memory versus **82/180** with deterministic verbatim storage—but the richer typed/raw hybrid reaches only **83/180**, and every preregistered hybrid-versus-verbatim/raw/typed comparison fails to reject. The hybrid also uses **174.205M tokens** versus **2.209M** for verbatim storage. This is evidence for persistence, not for the typed/sleep mechanism.

**KOPE** shows the systems upside of execution-grounded reuse: within the same GLM-5.2 workflow, active context management raises pass rate **60.0%→84.6%** while reducing optimization tokens **15.9B→1.113B**; removing Experience Graph Memory drops the full-suite pass rate to **55.2%**. But selection, compression, and injection still co-vary. **MemFuse**, **SCALE-QA / TSIM**, **The Compaction Cliff**, and **VoiceMem** make the same attribution pressure visible from different directions: access policy can dominate fused structure, episode reconstruction is package-level, preservation contracts need source-fidelity controls, and **134 ms** VoiceMem latency is retrieval latency rather than end-to-end interaction latency.

## Strongest evidence and negative controls

1. **When Stale Constraints Go Unchecked** — the cleanest fixed-budget causal diagnosis of verification allocation versus stale-memory use.
2. **DreamBench-SWE** — the strongest warning that a richer memory mechanism can fail to beat deterministic verbatim storage while costing far more.
3. **Recuris** — the strongest same-library separation of persistent artifacts from working state and invocation policy, plus a retry-matched negative result.
4. **MemFuse** — the clearest reminder that answer-time evidence completion can explain more than the fused representation being advertised.
5. **KOPE** — the strongest systems case that execution-grounded experience reuse can improve later tool decisions and reduce context load, while remaining internally bundled.

No August native-v2 paper is rated 5/5. All 25 closed-period records remain one-paper `early_signal` directions, so the durable Field Map is unchanged.

## Main tension, falsification, and reading path

The central tension is **better stored state versus better control over ordinary stored state**. Current evidence favors the second explanation more often than system papers imply, but three hidden assumptions could reverse that conclusion: qualification policies may rely on oracle provenance or privileged supervision; learned selectors may spend more compute than their controls; and “cheap online memory” may simply move extraction, verification, consolidation, or graph maintenance off the visible critical path.

The August thesis should weaken if a learned non-oracle qualification policy fails to improve later open-ended actions over a strong raw/verbatim archive; if same-library selector/invocation gains disappear after supervision and token/tool budgets are matched; or if structured memory mechanisms consistently beat verbatim/raw controls once construction, access, maintenance, retry, and reacquisition costs are equalized.

Minimal reading path: **DreamBench-SWE → StateMem → When Stale Constraints Go Unchecked → Recuris → KOPE**. Together they teach the month’s main correction from representation-first reasoning to lifecycle-matched causal attribution.

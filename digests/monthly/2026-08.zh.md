## 本月核心判断

八月最强的修正不是某个 architecture 胜出，而是：**只有在 matched simpler alternative 于某个具体 stage 失败时，复杂度才能在该 stage 获得 credit。** 当前 working map 是：

`archive / representation → state localization → access / expansion / admission → consumer-facing state → update / evolution → governance / cost / provenance`

8 月 18 日的论文把 retrieval 拆成 state localization、direct reach 与 complementary reach；把 evaluation 从 endpoint score 推向 promotion protocol；把 procedural evolution 从 self-reflection 推向 execution-grounded learning/certification。8 月 21 日新增 multi-source evidence completion、selector-local credit、judge qualification、guarded harness commit 与 training-side environment memory，但每个都只有一篇支撑。

8 月 24 日的三篇论文继续拆生命周期。**Remember, Verify, or Ask?** 把 authority/scope 放在 candidate commitment 之前，但只选择、不执行动作。**StateMemBench / StateMem** 区分 retrieved history 与 current operative state；persistent evidence 主要来自 supersession/recompute guidance，最干净的 consumer-side control 则来自 full-transcript wrapper。**MemTrapBench** 直接测 retrieval 后的错误复用，但它有意构造无需历史即可回答、prior history 含 trap 的压力测试。

## Design-space movement

### 1. Retrieval → state localization + direct/complementary reach

**ReFind** 仍是 raw-state control。**ArborMem** 把 active-state localization 放到 relevance retrieval 之前；**CABLE** 要求 link 相对 host retriever 真正扩展 reach；**RippleMem** 用 first-hop memory 搜索缺失证据；**MemFuse** 说明 multi-source fusion 的最大 ablation 仍在 answer-time access。当前最合理的拆法是：

`active-state localization → seed retrieval / selection → complementary or multi-source completion → admission`

### 2. Endpoint score → gate qualification + promotion evidence

**D²ACCI** 要求 paired effect、protected-slice non-regression 与 stage trace；**Competence, Not Accuracy** 要求 reference-free judge 在 same-question candidate distribution 上有判别力；**Explicit State Elicitation Is Not Enough** 说明 interpretable state 不等于 causal state。**Remember, Verify, or Ask?** 再增加一个约束：commitment label 不等于已执行、会改善 later behavior 的 write policy。

### 3. Retrieved evidence → operative state → applicable consumer state

**QCR** 与 **QUMem** 已经表明 retrieved evidence 和 actor-facing state 是不同对象。**StateMem** 增加 supersession 与 recomputation；但 dependency propagation 在 DeepSeek 上总体负增益，且 answer-time wrapper 的强结果不能归给 persistent store。**MemTrapBench** 增加负向 stress test：相关历史也可能不适用于当前任务；但尚未在同一 mixed workload 中同时测 useful-memory retention 与 trap rejection。

### 4. Self-improvement → execution-grounded state transition

**SkillEvo** 强调 feedback surface；**WER** 从 execution outcome 学 skill writer；**TRUSS** 用 static obligation、shadow execution 与 provenance trace 做 artifact certification；**ERSkill** 演化 read policy；**HCL** 把整个 harness 当作 commit unit；**SPADE** 把持久状态放进 curriculum generator。它们改变的是不同 state location，不能统一归为“self-evolving memory gain”。

### 5. Write/update contract 与 lifecycle economics

**LycheeMemory V2** 隔离 consolidation cadence，**FTA-Mem** 给出 density-dependent granularity，**Total Recall** 要求计入 ingest/reflection/retrieval 的全周期成本。**StateMem** 则把旧值保留用于 audit、同时从 active state 退休；每个 scenario 约 165–600 次 ingest call，使 supersession 的能力证据必须与 maintenance cost 一起解释。

## 本月最值得读的证据组合

1. **ReFind + ArborMem + CABLE + MemFuse + RippleMem**：目前最完整的 read-path 分解。
2. **D²ACCI + Competence + Remember/Verify/Ask + Explicit State Elicitation + Demystifying Agent Skills**：endpoint、label、explicit state 与 unaudited gate 都不够。
3. **StateMem + QUMem + QCR + MemTrapBench**：retrieved history、current operative state 与 consumer applicability 属于不同阶段；其中 StateMem 证据最强，MemTrap 仍是 stress-test signal。
4. **SkillGate + SkillEvo + WER + SPADE + TRUSS + ERSkill + HCL**：procedural evolution 分布在 selector、curriculum、writer、artifact、read policy 与 harness commit。
5. **LycheeMemory V2 + FTA-Mem + Total Recall + AuthMem-Bench/SkillJack**：write policy、成本、authority 与 descendant state 都是一等约束。

目前没有 5/5 论文。External validity 仍集中在 conversational QA、personalized generation、benchmark web/tool agent、cloud-support skill 与受控 evolution environment。

## 增强与减弱的主题

**增强：** competent raw-state control；state localization；retriever-complementary / multi-source completion；stage-specific supervision；admission/abstention；consumer-state reconstruction；gate qualification；execution-grounded learning；guarded commit；完整 cost/provenance。

**需要观察的 early signal：** authority-aware candidate commitment、supersession/recomputation、retrieval 后 applicability/harm。目前每项只有一篇 accepted support，不能表述为增强趋势。

**减弱：** one-shot top-k 作为 flat-memory baseline；没有 reachability claim 的 graph；把 retrieval 当作单一 causal stage；用 selected label 代替 safe persistence 证据；用 explicit state 代替 causal mechanism；用 endpoint success 代替 deployment evidence。

## 什么证据会推翻当前判断

如果 state localization 在自然长程交互中无效；matched online search 关闭 CABLE/RippleMem 增益；supersession/recompute 在外部 acting workload 上不能迁移；mixed workload 显示 applicability gate 大量误拒有用 memory；或 promotion protocol 无法预测真实 deployment failure，当前 map 应当收缩。

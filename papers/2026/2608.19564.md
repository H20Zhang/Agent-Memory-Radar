# Remember, Verify, or Ask? Cross-Family Evaluation of Memory Commitment in LLM Agents

[← Latest Papers](../../README.en.md#latest-papers) · [Research Map](../../README.en.md#research-map) · [Evaluation & Analysis](../../categories/evaluation-analysis.md) · [中文](2608.19564.zh.md)

**Paper:** [arXiv:2608.19564](https://arxiv.org/abs/2608.19564) · **Published:** 2026-08-20 · **Importance:** 3/5 · **Confidence:** Medium
**Tags:** `semantic` `text` `personalization` `general-agent`

> **Research delta.** MCB turns memory admission into four authority-aware actions—persist, use ephemerally, verify the world, or clarify with the user—and shows that a model's verbal choice is a weak proxy for its structured tool selection. It does not execute those actions or measure later memory behavior.

## Problem

Information acquired in one interaction should not automatically become durable agent state. A temporary formatting instruction, a changing service status, and an ambiguous reference require different decisions about scope and authority.

## Mechanism

Each MCB item supplies an acquisition context, a candidate update, and a later reuse context. The model chooses `persist`, `ephemeral`, `verify`, or `clarify`. The held-out set contains 70 items, plus a separate 70-item contrast extension. Two non-authors independently audited the test and contrast labels; overall agreement was **97.1%** with **κ=0.962**, and a blind third resolver handled four primary disagreements.

Label mode compares a bare prompt, five explicit commitment rules, and four demonstrations. MCB-Act removes the label vocabulary and requires one structured call: `memory_write`, `use_now`, `check_source`, or `ask_user`.

## Compared with

The closest prompt control holds model and held-out items fixed while changing only the commitment instructions or demonstrations. Always-Persist is a useful lifecycle-specific negative reference, but it is not a functioning no-memory system. MCB supplies the candidate directly; it does not compare stores, retrieval policies, or forgetting mechanisms.

## Decisive evidence

For Qwen3.5-9B, few-shot prompting raises accuracy from **0.557→0.771** (Holm-adjusted exact McNemar **p=0.002**), but clarification recall reaches only **0.333**. The policy prompt reduces erroneous persistence from **0.243→0.100** (**p=0.038**) while its accuracy gain is not significant; most uncertainty shifts to world verification rather than asking the user.

Stated decisions do not reliably survive the interface change. Label–tool agreement is **0.571** for each Claude model and **0.229** for Qwen. Qwen falls **0.557→0.343** in structured-call mode (**p=0.047**), largely by overusing `use_now` and collapsing verification recall.

## Main caveat

This is a 70-item synthetic held-out test with only 12 clarification cases and 10 items per category. The hidden category-majority oracle already reaches **0.800**; the explicit policy restates the labeling rules, and the contrast templates are closely rule-aligned. Effects are heterogeneous across the three checkpoints.

Most importantly, MCB-Act **selects but does not execute** a write, source check, or question. No state is later retrieved and no downstream utility is observed. The label–tool comparison also changes interface and output budget. The paper reports no aggregate token, latency, compute, dollar, energy, or maintenance cost, and the promised reproducibility artifact has no primary-source locator.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | Select durable persistence, ephemeral use, world verification, or user clarification; do not execute it. |
| Organize | Four actions encode authority and scope rather than topic. |
| Read | Candidate information and later reuse context are supplied directly; there is no retrieval system. |
| Update / forget | Not evaluated; the benchmark stops before commitment and later reuse. |

## Why it matters

Memory governance begins before storage. A safe agent must distinguish which source can resolve uncertainty and whether information is authorized to affect future behavior. MCB makes that boundary measurable, but remains an early benchmark signal rather than evidence of an improved persistent-memory policy.

# Hindsight Memory-PRM：用可审计的 Hindsight Credit 监督记忆管理

[← 最新论文](../../README.md#latest-papers) · [领域地图](../../README.md#field-map) · [Memory Learning & Evolution](../../categories/zh/memory-learning-evolution.md) · [English](2608.29605.md)

**论文：** [arXiv:2608.29605](https://arxiv.org/abs/2608.29605) · **发布日期：** 2026-08-30 · **重要性：** 5/5

> **研究增量。** Hindsight Memory-PRM 把 memory-policy credit 变成可审计对象：在同一 memory scaffold 和固定 reader 下，分别测 episode reward、observational use 与 controlled deletion。值得关注的是监督落在哪一层，而不是又一种存储结构。

## 问题

长周期 manager 要先做数十次 Write/Merge/Noop，最后才看到 episode score。Outcome-only RL 无法区分：某条持久记忆后来真的改变了行为，还是它只是与成功 trajectory 同时出现。

## 机制

系统记录所有 managed read path 与 answer citation。若 entry 从未进入任何读取路径，在论文声明的 retrieval invariant 下可以直接判为零贡献；对 source-anchored probe，再删除被引用 entry 并重答一次。离线用这些信号训练 operation-conditioned memory-utility critic，在线则形成 ordinal entry-presence credit，再沿非破坏性的 version chain 传播成 action-level proxy。

## 与什么比较

最关键的是同一 scaffold 内的 untrained/SFT、outcome-only GRPO、observational attribution 与完整 intervention-calibrated 方法。Matched-scale 和 shuffled-flip 用来排除“只是 reward 更密/尺度更大”的解释。外部 memory system 因接口不同，只能作为 system-level reference。

## 决定性证据

LoCoMo 在同一 retriever、reader 与 judge 下为 **58.6 untrained → 62.5 SFT → 63.4 outcome-only → 70.2 observational → 77.5 full**。最后 **+7.3pt** 只增加 flip-promotion/toxicity branch；matched-scale 与 shuffled-flip 只有 **70.6/70.5**。删除从未进入任何 logged read path 的 **74.6%** 条目只改变 **−0.1pt**，而删除 cited entry 会损失 **12.4pt**。LongMemEval 也出现 **66.0 → 72.5 → 79.0** 的同类 ladder。

## 主要限制

Deletion 识别的是“最终 **entry 对固定 reader/probe 是否必要**”，不是原始 Write/Merge action 的理想反事实价值；version-chain credit 仍是 proxy（抽样 replay Spearman **0.72**）。Schema 也没有完全迁移：LoCoMo checkpoint 直接到 LongMemEval 只有 **58.4**，不重训 policy、只适配 schema 可到 **71.2**，native training 为 **79.0**。监督成本很高：三次 LoCoMo seed 约 **1.6M API calls / $1.1k**，LongMemEval 约 **9.8M / $6.5k**。

## 记忆生命周期

`conversation → Write/Merge/Noop → event/profile/verbatim layer + version chain → deterministic retrieval → citation/deletion audit → critic + intervention-calibrated policy learning`

该实验刻意采用 lossless lifecycle；destructive forgetting、privacy deletion、retention budget 与 revocation 都没有被证明。

## 为什么重要

它提高了 learned memory manager 的证据门槛。以后应分别报告 **entry-presence utility、action-level credit、完整 supervision cost**，而不是把 packaged trajectory 的总增益直接记到 memory writer 名下。

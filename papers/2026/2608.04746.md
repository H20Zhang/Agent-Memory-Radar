# Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems

**arXiv:** [2608.04746](https://arxiv.org/abs/2608.04746) · **Published:** 2026-08-05 · **Category:** Write, Update & Consolidation · **Importance:** 4/5 · **AI confidence:** High

**Tags:** `episodic` `structured` `timeline` `general-agent`

> **TL;DR.** Make memory value explicitly time-dependent: each episodic memory carries What-Where-When context plus perishability and a utility horizon, so retention and retrieval can adapt to how facts age.

## Problem

Similarity retrieval treats old memories as uniformly useful. Global recency heuristics are only slightly better: they still cannot distinguish a durable fact from information whose value rapidly expires.

## Core idea

Attach **What-Where-When** structure and per-memory temporal utility parameters to episodic memories, combine them with query-adaptive retrieval, and retroactively revise context/utility when later evidence changes what an older event means.

## Memory design

| Stage | Design |
|---|---|
| Write | Structured episodic entries with What-Where-When context, perishability, and a utility horizon. |
| Organize | Temporal utility is local to each memory rather than one global decay function. |
| Read | Query-adaptive scoring combines semantic relevance, contextual fit, and time-dependent utility. |
| Update / forget | Retroactive integration updates earlier memories; per-memory decay suppresses memories after their useful horizon. |

## Compared to what

The strongest comparison is against **Mem0**, dense embedding retrieval, and global-recency / temporal-prompt baselines. The conceptual delta is that time affects each memory differently rather than acting as a universal recency feature.

## Evidence

On **EventQA-64k**, the paper reports **+2.66 F1 over Mem0** and **+3.09 over Qwen3-Embedding-4B retrieval** in the highlighted Llama 3.1 setting. On its controlled TGT diagnostic, the reported generalization gap improves by **0.108**; removing decay degrades the key metric by roughly **5.7×**.

## Why it matters

For long-lived agents, forgetting should be an estimate of **future utility**, not a garbage-collection heuristic. This paper gives that idea a concrete memory abstraction.

## Limitations / questions

- Gains concentrate on temporal reasoning over perishable facts; stronger dense retrieval can match some settings.
- Flat retrieval remains stronger in some conflict/fact-consolidation cases.
- TGT is a controlled diagnostic, so open-ended-agent external validity remains uncertain.

**Curator take:** **4/5**. The mechanism is narrow but conceptually clean; worth watching because temporal utility is likely a first-class lifecycle signal.

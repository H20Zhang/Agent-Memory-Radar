# InjecMEM: Memory Injection Attack on LLM Agent Memory Systems

[← Latest Papers](../../README.en.md#latest-papers) · [Research Map](../../README.en.md#field-map) · [Evaluation & Analysis](../../categories/evaluation-analysis.md) · [中文](2608.23471.zh.md)

**Paper:** [arXiv:2608.23471](https://arxiv.org/abs/2608.23471) · **Published:** 2026-08-24 · **Importance:** 4/5 · **Confidence:** Medium · **Artifact:** [Code](https://github.com/BlueBlood6/InjecMEM)

> **Research delta.** One ordinary interaction can seed a persistent record that is later retrieved and steers related responses. The honest end-to-end ceiling is 35.6% on MemoryOS, not conditional steering success.

## Problem

An attacker without store read/edit access may still exploit the normal write–retrieve path to influence a later consumer.

## Mechanism

InjecMEM combines a topical retrieval anchor with a short command optimized across surrogate prompts, positions, and lengths. One interaction writes the pair; a later related query retrieves it into the actor prompt.

## Compared with

Retrieval compares paraphrase+Multi-GCG under the same evaluation. Steering compares DPI, BadChain, vanilla GCG, and Multi-GCG, though the last receives more surrogates and position/length diversity. MemoryOS and MemGPT expose end-to-end transfer.

## Decisive evidence

MemoryOS reaches **46.5% retrieval**, **76.6% conditional steering**, and **35.6% joint success**; MemGPT reaches **37.2/48.6/18.1**. At top-50 drift, retrieval averages **35.4%**. Perplexity filtering blocks the attack but blocks **71.8%** of benign inputs.

## Main caveat

The strongest setting is white-box; same-family transfer needs joint optimization and held-out Llama transfer is zero. The memory must retain near-verbatim text, real-background tests cover two domains, and the target is a non-operational marker. Surrogate/optimization compute, GPU-hours, energy, dollars, defense latency, and non-target utility are incomplete.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | One attacker interaction enters the ordinary memory path. |
| Organize | MemoryOS/MemGPT retain and age a near-verbatim record. |
| Read | Related queries retrieve the record into fused actor context. |
| Update / forget | Drift is tested; rewrite, repair, deletion, and expiry are not. |

## Why it matters

Memory security must join write success, later retrieval, and actual consumer influence while measuring benign utility.

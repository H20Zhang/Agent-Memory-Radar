> **Research delta.** DreamBench-SWE 把 memory hygiene 变成 executable test：早期 session 注入的证据必须改变后续 repository patch。它证明持久状态在构造任务上有用，却没有证明 typed consolidation 或 sleep 优于 verbatim storage。

## Problem

Recall score 无法说明 Agent 是否正确应用先前项目状态、解决 supersession、拒绝错误经验，并最终提交可执行的代码修改。

## Mechanism

S1/S2 注入无法从 S3 推断的项目证据，S3 要求使用这些证据，hidden executable oracle 检查最终 repository。十类 construct 覆盖 retention、scope、contradiction、update propagation、provenance、synthesis、procedure、spurious lesson 与 abstention。

Reference probe 保存 immutable raw episode，并生成 typed record。Sleep 负责 consolidation、failure extraction、counterfactual replay、contradiction repair 与 stale suppression；read path 再按 status、scope、validity、supersession、risk、staleness、provenance 与 type 做 gate，最后由 wake actor 修改代码。

## Compared with

要判断 persistent state 是否有用，最接近的对照是相同 wake model、任务、工具与 read budget 下的 no external memory 和 deterministic verbatim storage。要判断 typed mechanism 是否有用，则 hybrid 必须在配平 maintenance compute 后胜过 verbatim、raw-only 与 typed-only；论文没有做到。

## Decisive evidence

v2.1 中，no memory 通过 **21/180 (.1167)**，verbatim **82/180 (.4556)**，hybrid **83/180 (.4611)**，literal-storage Mem0 **97/180 (.5389)**。因此早期持久证据确实改变后续 executable patch。

但 mechanism attribution 是负结果：hybrid 对 verbatim、raw-only、typed-only 的 preregistered test 全部未拒绝；hybrid/raw read 中 contradiction record 出现次数为 **0/180**。Hybrid 的 useful-memory precision（**.264**）也低于 verbatim（**.556**）。

## Main caveat

Fixture task 高度人工设计，而且以精确记忆为主：22 个 historical trap 中有 18 个属于 recall-verbatim。最终只有一个 hosted wake-model family 可行；native Mem0 与 Supermemory 的 mechanism contrast 因 frozen conformance 失败而无法运行，部分 stratum 对 no-memory 已无 headroom。

成本表揭示了更大的问题：hybrid 使用 **174.205M tokens、12,655 次 judge call**，verbatim 仅 **2.209M tokens**；p95 latency 为 **3503s vs 505s**。相近的记录美元成本掩盖了巨大的 maintenance intensity；storage、production operation、hosted-service price 与 energy 仍不完整。

## Memory lifecycle

| 阶段 | 设计 |
|---|---|
| Write | Raw session 与 typed record 保存项目证据、feedback、constraint 与 contradiction。 |
| Organize | Sleep 做 consolidation、repair、replay 与 stale marking。 |
| Read | 固定 budget 的 gate 决定什么进入后续 coding actor。 |
| Update / forget | Raw evidence 不变，过期 typed state 通过 logical suppression 退出。 |

## Why it matters

Memory benchmark 应先要求持久状态改变后续行为，再让每个昂贵的 hygiene mechanism 与强 verbatim archive 单独对照。

# CONTRAMEM：从多模型对比轨迹学习 Procedural Memory

[English](2608.22533.md) · [← 最新论文](../../README.md#latest-papers) · [领域地图](../../README.md#field-map) · [记忆学习与演化](../../categories/zh/memory-learning-evolution.md)

**Paper:** [arXiv:2608.22533](https://arxiv.org/abs/2608.22533) · **Published:** 2026-08-23 · **Importance:** 4/5 · **Confidence:** Medium

> **Research delta.** 同任务的 outcome variation 可以监督紧凑 procedural bank；现有证据支持“heterogeneous contrast + curation”这个 package，不支持 online self-evolution 或 contrast 单组件归因。

## Problem

一条成功轨迹缺少 failure、recovery 与跨模型差异，难以形成可迁移 procedure。

## Mechanism

CONTRAMEM 规范化轨迹、比较 outcome、生成局部 delta，再通过 ADD/PATCH/MERGE/NARROW/NOOP 维护 Function/Skill Card；测试时 BM25 最多返回三张 card。

## Compared with

最接近的对照是同 pipeline 的 no-memory/self-memory、相同 delta/retrieval 的 append-only，以及三条 GPT-5.5 rollout 与三条异构轨迹的配平比较。

## Decisive evidence

Held-out source macro success 为 **26.2%** no-memory、**47.2%** self-memory、**55.3%** shared contrastive；unseen Qwen 为 **18.5→35.5**。三轨迹配平时 **70.0→77.5**；curation 将 **65.0→71.9**，同时把 card 从 **273 减到 205**。

## Main caveat

评估时 bank 已冻结，因此是 offline construction。更广的成功行为覆盖仍是替代解释；23 个 regression 包括 Claude Adaptability 与 Time。Source generation、reflection、verifier/judge、maintenance、latency、美元与 energy 均不完整。

## Memory lifecycle

| 阶段 | 设计 |
|---|---|
| Write | 异构轨迹对比后形成 procedural delta。 |
| Organize | Local curation 维护 Function/Skill Card。 |
| Read | BM25 最多暴露三张 card。 |
| Update / forget | 测了 offline merge/narrow；未测在线更新和 stale retirement。 |

## Why it matters

Procedural memory 或许应从受控 outcome variation 学习，但必须区分 contrast 与 coverage。

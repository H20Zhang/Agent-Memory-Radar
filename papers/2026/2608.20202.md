# MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use

> **Research delta.** MemTrapBench makes post-retrieval applicability a measurable failure boundary: semantically related history can worsen the current answer. Its no-memory advantage is conditional on an adversarial stress-test distribution, and AdaptiveMem is a taxonomy-matched prompt rather than a validated general admission policy.

## Problem

Memory evaluation usually asks whether the system extracted and retrieved the right information. Valid and relevant history can still anchor the actor on an obsolete strategy, an exceptional prior case, or a poisoned belief.

## Mechanism

The benchmark contains 1,050 synthetic histories: 350 Task Boundary, 350 Cognitive Bias, 200 Safety, and 150 Trauma instances. GPT-5.4 expands human-authored seeds into 18–40-turn conversations. Every final query is designed to be independently solvable, while prior dialogue plants a reasoning-fixation or belief-distortion trap.

The paper compares no memory, full history, and four memory frameworks on Gemini-3-Flash-Preview and Qwen3-30B-A3B-Instruct-2507. AdaptiveMem is an answer-time system prompt that names the four trap types and asks the model to identify the live task, reject inapplicable history, and prioritize the current query.

## Compared with

No-memory cleanly tests whether adding history changes the answer, but intentionally advantages the standalone-solvable current query. The closest lifecycle-matched evidence is a limited trap-free control that preserves the task and relevant history while removing the designed trap; it is reported only for Task Boundary and Trauma.

AdaptiveMem comparisons hold the selected framework fixed, but lack a length-matched neutral warning prompt, unseen trap categories, and a mixed workload measuring false rejection of useful memory.

## Decisive evidence

On Gemini, no-memory averages **85.16**, while the strongest memory arm, EverMemOS, reaches **71.17**. On Qwen, no-memory is **81.83**; FullText is **70.99** and LightMem **70.13**. These are four-dimension judge scores rather than simple accuracy rates, and not every subgroup is negative—Qwen FullText improves on Trauma **87.17→90.27**.

The limited matched controls are more informative. Task Boundary scores **92.29** without memory, **94.39** with trap-free history, and **31.05** with trap-inducing history. Trauma scores **86.73 / 84.33 / 69.43**. This supports a causal effect of trap semantics on later answers within those synthetic subsets.

AdaptiveMem adds **11.8 / 14.9 / 11.3 points** across three Gemini memory arms and **4.2 / 2.5 / 2.6** on Qwen; the 200-item samples have no uncertainty estimates.

## Main caveat

MemTrapBench is an adversarial diagnostic: every current query is constructed to need no history while prior dialogue is generated to plant a trap. The large no-memory advantage therefore measures conditional susceptibility, not trap prevalence or memory's net real-world utility. QC lacks annotator counts, agreement, rejection rates, and a released audit; framework versions, retrieval budgets, and configurations are also missing.

Headline scores average LLM-judged correctness, format, relevance, and efficiency. Table 1 provides no confidence intervals or paired tests, and judge absolute scores differ materially. AdaptiveMem explicitly describes the benchmark taxonomy, so its result is benchmark-aligned prompt mitigation. No ingestion, access, latency, token, storage, dollar, maintenance, or forgetting cost is reported.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | Generated histories are ingested by full context or four unmatched memory packages. |
| Organize | Framework-specific compression and hierarchy are not isolated. |
| Read | Retrieved/full history changes the final answer; AdaptiveMem adds an applicability check before use. |
| Update / forget | Not tested; there is no evolving stream, expiry, conflict repair, or maintenance policy. |

## Why it matters

Retrieval correctness is not enough. The actor needs an admission decision that preserves helpful evidence while declining misleading prior context. MemTrapBench is a useful early signal for this consumer-side boundary, not evidence that memory is generally harmful or that one prompt solves admission.

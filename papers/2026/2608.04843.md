# MemoryCPT: An End-to-End Agent Memory Framework for Cost-Performance Trade-off

**arXiv:** [2608.04843](https://arxiv.org/abs/2608.04843) · **Published:** 2026-08-05 · **Category:** Memory Learning & Evolution · **Importance:** 4/5 · **AI confidence:** High

**Tags:** `episodic` `semantic` `structured` `general-agent`

> **TL;DR.** MemoryCPT jointly learns offline memory construction and online query-conditioned compression, explicitly optimizing answer quality against inference cost rather than treating the memory pipeline as fixed heuristics.

## Problem

Multi-stage memory systems repeatedly invoke LLMs for segmentation, abstraction, retrieval, and summarization. That creates a cost-quality trade-off that hand-built pipelines optimize only indirectly.

## Core idea

**QAD** distills several construction roles into a Qwen2.5-7B model using supervised reasoning traces. **QAR** fuses dense and sparse retrieval and then applies a GRPO-trained summarizer with a reward balancing answer quality and context cost.

## Memory design

| Stage | Design |
|---|---|
| Write | Learned construction emits episodic and semantic create/merge/abstract operations. |
| Organize | Complementary episodic and semantic stores. |
| Read | Dense+sparse retrieval via reciprocal-rank fusion, then query-aware learned compression before a frozen answer model. |
| Update / forget | Merge and abstraction are learned during construction; deletion/long-term forgetting is not central. |

## Compared to what

The important comparison is with **training-free modular pipelines** such as LightMem/MemoryOS, learned memory-policy approaches such as Memory-R1, and explicitly cost-aware baselines such as BudgetMem. MemoryCPT's main delta is that both write-time construction and read-time compression become trainable components of one cost-aware pipeline.

## Evidence

The paper evaluates **LoCoMo** and **LongMemEval**. In the reported aggregate ablation, removing QAR increases cost from **5.02 to 11.10** while reducing F1 from **0.482 to 0.309**; removing QAD also reduces answer quality. The full system is competitive in quality while using much less query context.

## Why it matters

This pushes agent memory toward a **learned systems optimization problem**: not merely “retrieve better,” but learn which transformations are worth their inference cost across the memory lifecycle.

## Limitations / questions

- Evidence is concentrated on conversational memory-QA rather than tool-using or environment-acting agents.
- Monetary cost depends on model pricing and amortization assumptions.
- Transfer of the learned construction policy across domains and changing memory distributions remains unclear.

**Curator take:** **4/5**. The end-to-end cost framing is important; the evidence is not yet broad enough to call it field-shaping.

# When Your Agent Opens the Chat App: Agent-Controlled Search over Raw Chat Logs Rivals Structured Memory

[← Latest Papers](../../README.md#latest-papers) · [Research Map](../../README.md#research-map) · [Retrieval & Access](../../categories/retrieval-access.md)

[arXiv 2608.12888](https://arxiv.org/abs/2608.12888) · Published 2026-08-13 · Importance **4/5** · Confidence **high**  
`episodic` `text` `timeline` `general-agent`

> **Research delta.** ReFind is the strongest current negative control against mandatory semantic preprocessing: a stateful agent searches the **raw chat archive** with lexical retrieval plus chat-native controls and can outperform compared graph/tree memories on precise refinding without LLM-based index construction.

## Problem

Structured memory systems commit to summaries, links, or compressed representations before the future question is known. That can discard evidence and adds a construction pipeline. A weak flat baseline therefore makes the comparison ambiguous: did the structured representation help, or did it simply expose a better access interface?

## Mechanism

ReFind preserves timestamped raw turns and moves adaptation to query time.

`keywords/time scope → turn-level BM25 → session-aware fusion → local context expansion → seen-session filtering → save verbatim evidence → reformulate or stop → answer`

The important nuance is that ReFind is not metadata-free. It uses native turns, sessions, and timestamps; what it avoids is **generated semantic memory structure** such as summaries, cards, trees, entities, or graphs.

## Compared with

Two controls make the paper especially useful:

- **Generic agentic BM25** keeps the multi-round controller, note-taking, answer stage, and BM25 backend but removes the chat-native controls.
- **One search** removes result-conditioned reformulation while keeping the first retrieval step.

The paper also compares with BM25-RAG and structured memory systems such as HippoRAG 2, RAPTOR, GraphRAG, Mem0, A-Mem, and Zep.

## Decisive evidence

Across six MemoryAgentBench tasks, ReFind reaches **58.2** macro-average versus **53.2** for HippoRAG 2 and **48.8** for BM25-RAG.

The more diagnostic LongMemEval-S/M result is:

| Access path | S | M |
|---|---:|---:|
| Full ReFind | **93.2±3.3** | **89.3±6.0** |
| Generic agentic BM25 | 78.7±4.6 | 82.2±3.8 |
| One search | 84.7±3.1 | 68.9±3.8 |

Iteration alone is therefore insufficient; the chat-native controls jointly matter. The evidence does **not** establish that lexical/raw retrieval dominates semantic structure on every memory workload.

## Main caveat

ReFind shifts work from memory construction to query time. The strongest runs use substantially more online tokens/latency than simpler controls, so the lifecycle comparison is incomplete unless offline construction and online search are charged together.

Open questions:

- Which workloads should precompute semantic structure and which should defer intelligence to question time?
- Does raw-record access remain competitive on semantic abstraction, multimodal memory, or acting-agent tasks?
- What happens when archive growth makes repeated lexical interaction itself the dominant cost?

## Memory lifecycle

| Stage | Design |
|---|---|
| **Write** | Append raw turns and update a turn-level BM25 index; no LLM construction pass. |
| **Organize** | Preserve native turn/session/timestamp structure; session identity informs ranking and deduplication. |
| **Read** | Iterative keyword/time search, session fusion, local expansion, seen-session filtering, saved verbatim evidence, then answer. |
| **Update / forget** | Append-only archive; no consolidation or forgetting. Query-time state tracks notes, seen sessions, and observations. |

## Why it matters

ReFind raises the baseline for every structured-memory paper. Before crediting semantic preprocessing, the system should beat a **competent substrate-native raw-record interface**, not only one-shot top-k retrieval.

# QUMem：Query-Conditioned User-State Reconstruction

**中文** | [English](2608.16168.md) · [返回首页](../../README.md) · [Research Library](../../library/README.md)

[Paper](https://arxiv.org/abs/2608.16168) · **Importance: 4/5**

> **Research delta.** QUMem 不把 retrieval 返回的历史片段直接当作最终 memory state，而是在当前 query 到来后，把这些片段作为证据联合重建**当前 user state**。它真正把新的 control boundary 放在 `retrieval → consumer state` 之间。

## Problem

很多长期记忆系统默认：只要把相关历史找出来，后续模型自然就能使用。但 personalization 场景里，单条历史信号往往有不同作用域、有效期和上下文；固定 turn/session 边界还可能把同一事件切碎，或者把不相关信号放在一起。

因此这里的核心失败不是“召回不到”，而是：**召回到的 evidence 仍不能直接代表当前用户到底处于什么状态、哪些 preference/constraint 此刻仍适用。**

## Mechanism

QUMem 分开 persistent evidence 与 downstream actor 真正消费的 state。

`history → semantic episodes → typed facts/preferences/insights → current-task information needs → typed multi-query retrieval → merged evidence → user-state reconstruction → response/action`

Write side 用 semantic continuity 形成 variable-length episode，再提取不同类型的 memory；read side 则先判断当前任务缺什么信息，再做 typed retrieval，最后联合推断当前 user state。

## Closest comparison

外部 baseline 包括 A-MEM、Mem0、Zep，但更有判别力的是内部 stage ablation：分别去掉 episode construction、typed decomposition、user-state reconstruction。

这让我们至少可以问：**增益主要来自更好的存储结构，还是 retrieval 之后的 state construction？**

仍然没有完全隔离的是：不同 stage 的实现和预算并非都被替换成强 matched alternative，因此结果更支持 QUMem 这套 pipeline，而不是证明某个唯一实现不可替代。

## Decisive evidence

PersonaMem + GPT-4o-mini：

- full QUMem: **61.02**
- w/o episode construction: **58.38**
- w/o typed decomposition: **57.11**
- w/o user-state reconstruction: **54.51**

最大掉点来自最后的 reconstruction。KnowU-Bench 上 overall success 为 **17.4%**，最强 baseline 为 **12.8%**。

这组结果最值得带走的不是“QUMem 排名第一”，而是：**consumer-state construction 可能比再加一层 memory schema 更接近 load-bearing stage。**

## What remains unproven

最关键的 follow-up 是固定 retrieved evidence 与 synthesis budget，只比较：raw evidence aggregation、provenance-aware summary、explicit user-state reconstruction。

还需要验证：episode boundary 在不同 dialogue/workload 下是否稳定；memory 冲突或 preference drift 时 reconstruction 会不会把不确定性变成错误的“当前状态”；三段 read-time inference 的 latency/token cost 是否值得。

## Field-map consequence

QUMem 强化了一个应该单独画出来的 boundary：

`archive / retrieved evidence ≠ actor-facing consumer state`

因此未来 personalized-memory baseline 不应只比较 top-k relevance；至少还要问 retrieved evidence 如何被联合解释、怎样处理 temporal validity 与冲突。

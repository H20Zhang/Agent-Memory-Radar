# When Memory Becomes Authority: Benchmarking Authorization Collapse in Agent Memory

**arXiv:** [2608.01679](https://arxiv.org/abs/2608.01679) · **Published:** 2026-08-03 · **Category:** Evaluation & Analysis · **Importance:** 4/5 · **AI confidence:** High

**Tags:** `semantic` `structured` `general-agent`

> **TL;DR.** Memory consolidation can preserve *what was said* while erasing *who was authorized to say it*, turning untrusted claims into apparently authoritative persistent state.

## Problem

Most memory systems optimize semantic retention. Operational agents also need to retain provenance and authorization constraints; otherwise compression can silently change the meaning of a remembered claim.

## Core idea

Build paired histories where the semantic claim and downstream task are held fixed but **source authority** changes. Measure whether existing consolidators preserve that difference, then test a source-first mitigation that persists an authority label alongside memory.

## Memory design

| Stage | Design under test |
|---|---|
| Write | Role/source-labeled histories are consolidated into persistent memory; the benchmark measures whether authority survives. |
| Organize | The mitigation stores authority/provenance with the consolidated claim instead of discarding it as metadata. |
| Read | A downstream action agent conditions behavior on remembered content and its authority label. |
| Update / forget | The study focuses on one consolidation-to-action cycle, not long-term revocation or authority changes. |

## Compared to what

The benchmark compares multiple existing **memory consolidators × LLM backbones**. The real baseline assumption being challenged is deeper: that a semantically faithful summary is necessarily a behaviorally faithful memory.

## Evidence

The paper reports **authority collapse in 48/49** consolidator/backbone configurations. Collapsed memories lead to a mean **50.3% unauthorized-action rate** in the benchmark. Persisting authority labels reduces the observed unauthorized-action rate from **16.9% to 0.0%** in the mitigation setting while benign-task success remains essentially unchanged.

## Why it matters

For tool-using agents, **provenance is part of semantics**. If consolidation forgets who had permission to authorize an action, the memory system has not merely compressed information—it has changed the agent's effective policy.

## Limitations / questions

- Controlled benchmark with synthetic paired histories and hand-specified authority relations.
- Only one write-to-action cycle; revocation, delegation, conflict, and organizational hierarchy are not yet modeled longitudinally.
- Scaling authority representations to realistic open-ended permissions remains untested.

**Curator take:** **4/5**, with upside. This may become a useful evaluation dimension because it exposes an invariant most current memory benchmarks do not measure.

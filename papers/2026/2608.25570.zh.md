# KOPE：Experience-Driven Kernel Optimization with Experience Graph Memory

[论文](https://arxiv.org/abs/2608.25570) · [English](2608.25570.md) · [Memory Learning & Evolution](../../categories/zh/memory-learning-evolution.md)

## Research delta

KOPE 把 execution feedback 持久化成 **decision→outcome experience graph**，并证明它能改变后续 tool decision、同时减少 context。它比“experience 有帮助”更有证据力，因为 active context 和 graph memory 都有 same-workflow ablation。

## Problem

kernel agent 会重复 compile/test/profile/revise，但一轮结束后通常把 target-hardware failure/win 丢掉；把全部 trajectory 塞回 context 又会让历史与当前任务争 token。

## Mechanism

每次 attempt 同时写成 narrative Journal 和 structured Case，保留 code change、correctness/performance outcome、confidence、predecessor id。Case 组成 decision-lineage graph；每轮前 Active Context Management 用 required hot state + graph-ranked warm experience + cold knowledge 重建 bounded prompt。

## Closest comparison

两组 control 最关键：完整 53-operator suite 上 **active vs passive context construction**，以及**同一 GLM-5.2 workflow 开/关 Experience Graph Memory**。

## Decisive evidence

Active context 把 pass rate 从 `636/1060→897/1060`（60.0%→84.6%），同时 aggregate optimization tokens 从 `15.9B→1.113B`（−93.0%），score 从 636.00→2004.49。打开 Experience Graph Memory 后 full-suite pass rate 55.2%→84.6%；412 个 paired positive timing case 上 graph-enabled condition 的 geometric-mean speedup ratio 为 **1.43×**。

## Main caveat

active-context ablation 同时变化 retrieval ranking、compression、injection。graph edge 只是 execution lineage，downstream-outcome score 也是 ranking heuristic，**不是 earlier decision 的 causal effect**。storage/index/graph maintenance 全生命周期成本仍不完整。

## Memory lifecycle

`compile/test/profile attempt → Journal + structured Case → decision-outcome graph → relevance/outcome ranking → bounded warm injection → next optimization decision/task`

foundation model 固定，evolve 的是 external persistent state。长期 consolidation、deletion、privacy、governance 没有评估。

## Why it matters

这里真正有用的 memory object 不是旧文本 summary，而是**和产生它的 decision 绑定的 measured execution evidence**。对于 tool-using agent，这是比 semantic similarity 更接近可复用经验的单位。

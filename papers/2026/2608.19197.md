# SPADE: Self-Play in Adaptive Synthetic Executable Environments

[← Latest Papers](../../README.en.md#latest-papers) · [Research Map](../../README.en.md#research-map) · [Memory Learning & Evolution](../../categories/memory-learning-evolution.md) · [中文](2608.19197.zh.md)

**Paper:** [arXiv:2608.19197](https://arxiv.org/abs/2608.19197) · **Published:** 2026-08-19 · **Importance:** 3/5 · **Confidence:** Medium
**Tags:** `procedural` `structured` `general-agent` · **Code:** [spade-rl/spade](https://github.com/spade-rl/spade) · **Project:** [SPADE](https://spade-rl.github.io/)

> **Research delta.** A bounded cross-episode memory supplies prior executable environments to a learned Environment Designer. Its removal lowers one 30B training package's selected benchmark average, but the result does not isolate regret-based retrieval or FIFO retention.

## Problem

Open-ended self-improvement needs training environments near the learner's current capability frontier. A stateless designer can repeat familiar tasks or drift toward environments that are too easy, too hard, or invalid.

## Mechanism

SPADE trains one LLM in two roles: an Environment Designer writes executable Gym-style environments, and a Reasoning Agent learns to act in them. Hint/no-hint reward gaps estimate regret. A persistent buffer stores environment code, skill, win rate, regret, and rollout identity.

Before the next generation call, the designer receives up to two same-skill high-regret snippets and one same-skill negative describing an environment that was too easy or too hard. The buffer holds at most 200 records and evicts oldest-first.

## Compared with

The closest control is the official `NO_ENV_MEMORY=1` launcher. It retains the 30B base model, corpus grounding, trainable designer, 400-rollout GRPO recipe, 24 environments, hint mechanism, and regeneration schedule. It removes the memory prompt path, however, so it also removes up to roughly 4,000 characters of demonstrations and one negative descriptor. No token-matched static, random, score-shuffled, or alternative-retention control is reported.

## Decisive evidence

The selected full checkpoint averages **58.3** across eight game benchmarks versus **53.2** without environment memory. The largest gaps are on Reasoning-Gym Math (**63.3 vs 49.1**), Algorithmic (**32.1 vs 22.9**), and Cognition (**37.7 vs 30.7**). AIME 2026 moves in the other direction (**74.4 full vs 75.0 without memory**).

The Aug 24 v2 revision adds full-package tool-use results for the 30B actor: **+5.7 points on BFCL-v4 MT** and **+13.9 on ACEBench-Agent**. These broaden package external validity but do not isolate environment memory.

Memory does not explain the reported diversity: Vendi/n is **0.68** full and **0.69** without memory, while removing corpus grounding collapses it to **0.04**. The evidence therefore supports a training-package contribution from the memory prompt path, not a general diversity or retrieval-policy claim.

## Main caveat

Each condition is one run, and every variant selects its best checkpoint on the same eight-benchmark suite used for the final table; full and no-memory peak at different steps. The memory ablation also changes prompt content and length, its sampler lacks an explicit seed in the released construction, and the public artifacts do not expose the exact no-memory checkpoint/log. The **5.1-point gap cannot be assigned specifically to regret ranking, the 200-record capacity, or FIFO forgetting**.

The overall pipeline is expensive: 400 rollouts, 24 environments, repeated hinted and unhinted plays, generation retries, validation, and one eight-GPU node. GPU-hours, tokens, wall time, dollars, and energy are not reported.

The v2 tool-use comparison is against external systems, not the same tool-use training pipeline with environment memory disabled; it cannot raise memory-component attribution.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | Append accepted environment code with skill, win rate, regret, and rollout metadata. |
| Organize | Flat skill-tagged buffer, bounded to 200 records. |
| Read | Inject two high-regret same-skill examples and one extreme negative into the next designer prompt. |
| Update / forget | Append from new outcomes; evict oldest-first. The final Reasoning Agent has no inference-time memory. |

## Why it matters

Agent memory can shape **which future experiences are generated for learning**, not only what a deployed actor retrieves. That training-side state deserves its own control and cost accounting. SPADE is an early signal for this boundary, not evidence that environment memory causes the full self-play gain.

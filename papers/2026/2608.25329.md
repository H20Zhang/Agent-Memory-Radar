# HiPS: Hierarchical Strategy Co-Evolution for Agent Memory

[← Latest Papers](../../README.en.md#latest-papers) · [Research Map](../../README.en.md#field-map) · [Memory Learning & Evolution](../../categories/memory-learning-evolution.md) · [中文](2608.25329.zh.md)

**Paper:** [arXiv:2608.25329](https://arxiv.org/abs/2608.25329) · **Published:** 2026-08-26 · **Importance:** 4/5

> **Research delta.** HiPS treats **memory-management policy** as persistent adaptive state: a globally shared rule layer plus persona-specific deltas. The important comparison is not its heterogeneous leaderboard but whether shared/personal rule boundaries change behavior under ablation and cross-model transfer.

## Problem

A static writer must decide what to retain, compress, or discard for every user. One global policy wastes recurring shared structure; one fully personalized policy can overfit exceptions and scales poorly.

## Mechanism

Universal Strategy Distillation extracts cross-persona management rules. Persona Delta Distillation adds local rules only when persona-specific predictive gain warrants them. Cross-Level Rule Flow promotes recurring personal rules upward and specializes contradicted global rules downward. A budgeted selector injects the relevant rules while task policy and management strategy co-evolve from outcome evidence.

## Compared with

Use component ablations and **universal-only vs universal+persona-delta transfer** before trusting the full-system table, because several published baselines use different model backbones/checkpoints.

## Decisive evidence

Full HiPS reports PersonaMem `73.49/62.01` versus MemSkill `64.45/55.37`, but that is not a fully matched control. More diagnostic PERMA ablations give full `66.95/56.56/63.83/56.30`, versus `45.39/40.87/43.12/36.50` without Cross-Level Rule Flow and `51.63/44.99/52.62/46.79` without persona gating. The learned strategy rules also transfer to different Qwen, GPT-4o-mini, Gemini 2.5 Flash, and GPT-5 consumers without carrying the original RL policy.

## Main caveat

The package jointly changes distillation, gating, rule flow, selection, and policy optimization. Headline baseline ranks are model-confounded. Evolution time grows markedly with dialogue length, while full maintenance/dollar/energy cost is missing.

## Memory lifecycle

`cross-persona outcomes → universal rules + gated persona deltas → budgeted rule injection → profile write/transform decisions → promote/specialize rules from later evidence`

This evolves the **policy governing memory**, not a complete privacy/deletion lifecycle for user facts.

## Why it matters

The next memory-design question is not only “what should be stored?” but **which storage/update rules should generalize across users, and which must remain local?** HiPS provides early evidence that this boundary is itself learnable state.

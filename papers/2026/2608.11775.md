# The Sleeping Agent: What Gist-Based Context Compression Loses and Why

**arXiv:** [2608.11775](https://arxiv.org/abs/2608.11775) · **Published:** 2026-08-12 · **Category:** Write, Update & Consolidation · **Importance:** 3/5 · **AI confidence:** High

**Tags:** `semantic` `text` `timeline` `general-agent` · **Code:** [kyrkewood/sleeping-agent](https://github.com/kyrkewood/sleeping-agent)

> **TL;DR.** Gist compression is **selective forgetting**. In the studied pipeline, a generic abstraction prompt preserved entities and event structure while deleting dates/times; one targeted prompt change recovered temporal evidence and temporal QA without materially changing the other content types.

## Problem

Long-horizon agents commonly compress older context when the active window fills. Aggregate accuracy can hide a systematic representation loss: the summary may preserve “what happened” while dropping the temporal anchors needed for later “when?” questions.

## Core idea

Use Salience-Weighted Consolidation (SWC) as a diagnostic probe. Score history chunks by salience, keep high-priority material, gist-abstract mid-priority material, then measure preservation and downstream accuracy by question type. Modify only the gist prompt to explicitly retain dates and times and test whether the specific failure recovers.

## Memory design

| Stage | Design |
|---|---|
| Write | Salience-score history; retain high-priority chunks and rewrite mid-priority chunks as structured gist. |
| Organize | Priority tiers determine what stays verbatim versus compressed. |
| Read | The answer model consumes the compressed context directly; no external retrieval store is introduced. |
| Update / forget | Reactive compression replaces older context under a budget. Online scheduling is not evaluated on the offline benchmark. |

## Compared to what

The paper compares recent-token **truncation**, a **sliding-window summarizer**, SWC with/without temporal protection, and limited **full context** as a reference ceiling. The most informative comparison is the same SWC pipeline with one prompt-level preservation rule changed.

## Evidence

Across all ten LoCoMo conversations, verbatim temporal-expression preservation rises from **3.05% to 62.39% (~20×)** after the one-sentence temporal-protection change. Named-entity and event preservation barely move (**1.02× / 1.11×**), so the intervention is selective rather than a general verbosity increase.

On matched temporal questions, the change recovers **+0.314 [0.254, 0.375]** judge accuracy. The paper does not claim SWC is a state-of-the-art memory system; the value is the mechanism diagnosis.

## Why it matters

A compression operator needs a **preservation contract**, not an instruction to “keep the gist.” Small information classes—timestamps, authority, provenance, identifiers—can be low-volume yet decision-critical. Aggregate compression quality can therefore hide the exact semantic field that later breaks the agent.

## Limitations / questions

- Temporal protection is tested only inside SWC on LoCoMo.
- Full-context reference is evaluated on only two conversations.
- Verbatim preservation undercounts semantically faithful paraphrases.
- Online scheduling/forgetting is not testable here; open-domain differences are not reliable.

**Curator take:** **3/5.** Narrow but useful diagnostic evidence. The broader design point becomes important only if similar field-specific loss recurs across independently designed memory compressors.

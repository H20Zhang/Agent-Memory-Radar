# CABLE：用“互补可达性”而不是语义相似性来建 Memory Link

[English](2608.17911.md) · [← 最新论文](../../README.md#latest) · [Research Library](../../library/README.md)

**Paper:** [arXiv:2608.17911](https://arxiv.org/abs/2608.17911) · **Importance:** 4/5

> **Research delta.** CABLE 判断一条 memory edge 是否值得存，不看它“像不像”，而看它能否到达 host retriever 原本到不了的证据。Graph structure 因此被定义成 **retriever-complementary operator**。

## 还没被解决的问题

一个 graph 可以很丰富，却只是把 dense/sparse retriever 已经能找到的 semantic neighbors 再连一遍。这样 write-time 花了额外 inference，却没有扩大 bounded retrieval 的 evidence reach。

## Mechanism

`direct semantic neighborhood + antecedent-query candidates → 去掉 overlap → verify complementary candidates → 写 directed links`

Query time 先做 host retrieval，再从 seed 做 one-hop expansion，用 novelty filter 替换低排名结果；最终 evidence count 不增加。

## 最近的公平比较

最有判别力的 control 是 **同一个 A-MEM host retriever + 同样最终 evidence-count budget**。因此主要变量是“哪些 item 进入 bounded set”，而不是给 downstream model 更多 context。

## 决定性证据

A-MEM + CABLE 在 LoCoMo Qwen3.5 上 **71.23→74.81**，MA-LongMemEval Qwen 上 **59.33→65.33**。去掉 direct-neighborhood subtraction 或 candidate verification 都会损失一部分收益。

但 temporal-reasoning slice 在两个报告设置里分别下降 **1.33 / 2.67 points**，说明 complementary expansion 并非无条件有益。

## 仍未证明什么

成本被移到 ingestion：antecedent-query generation、candidate retrieval、verification 都要付 write-time inference。论文没有把这些 construction cost 与一个同样强的 online-search baseline 做完整 lifecycle matching。

## 对领域地图的影响

CABLE 给 structured memory 一个更严格的标准：**edge 只有在改变相对于 host retrieval interface 的 reachability 时才值得存在。** 这比“graph 可能帮助 retrieval”更可检验。

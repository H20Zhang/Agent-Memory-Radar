# Towards a Formal Definition of Agent Memory: Basis, Span, Optimality, and the Sequential Memory Problem

**arXiv:** [2608.11654](https://arxiv.org/abs/2608.11654) · **Published:** 2026-08-12 · **Category:** Evaluation & Analysis · **Importance:** 3/5 · **AI confidence:** High

**Tags:** `general-agent`

> **TL;DR.** A preliminary formal theory of agent memory: stored events are a **basis**, the knowledge they generate is its **span**, memory quality becomes coverage under a capacity budget, and sequential writing becomes an MDP with delayed query-time reward.

## Problem

The field calls summaries, graphs, reflections, vector stores, and parameter changes “memory,” then evaluates them with incompatible metrics. That makes two basic questions surprisingly hard to state: **what is a memory**, and **what does optimal memory mean at a fixed capacity?**

## Core idea

Let a memory store a subset of events from some material. A generation operator `Phi` maps those events to the knowledge they entail. Under the paper's **single-item support** assumption, a query is answerable if one item in that span covers it, turning memory construction into a capacity-constrained coverage problem.

The optimal value at capacity `S` defines a **utility–capacity frontier**. With noisy extraction, the paper separates claimed coverage from truth-aware precision. With an unknown future query distribution, it reframes writing as a sequential MDP in which memory is state, writes are actions, and later query utility provides delayed reward.

## Memory design

| Stage | Formal role |
|---|---|
| Write | Select a bounded subset of events; sequentially, writing is an action whose utility is revealed by later queries. |
| Organize | Stored events are the basis; `Phi(memory)` is the semantic span. Under noise, asserted span is distinguished from the true/good span. |
| Read | A read policy retrieves from the span; the core coverage theory assumes one knowledge item suffices per query. |
| Update / forget | Memory state may change under a capacity constraint in the MDP, but no concrete replacement or forgetting algorithm is proposed. |

## Compared to what

This is not an empirical system paper. It maps representative memory systems into a common write/read/reasoning view rather than claiming benchmark superiority. The intended comparison is a **yardstick**: for a given material, query distribution, and capacity, how close is a write policy to the best achievable coverage frontier?

## Evidence

The strongest results are theoretical. Under monotonicity, the utility–capacity frontier is non-decreasing and saturates at the full-context baseline. If `Phi` is decomposable, the capacity-constrained problem reduces to weighted maximum coverage and greedy selection inherits the classical **(1−1/e)** approximation; cross-event synergy removes that guarantee.

The Odyssey example makes the definitions concrete, but it is illustrative. There is no broad empirical study showing that frontier distance predicts end-to-end quality for current agent-memory systems.

## Why it matters

The most useful separation is **memory availability vs reasoning correctness**. The framework makes it harder to claim that a memory is “better” merely because downstream answer accuracy rose: one can ask whether the write policy improved information coverage, whether extraction introduced false knowledge, or whether the reasoner simply used the same memory better.

## Limitations / questions

- **Single-item support** excludes answer-time composition; reasoning chains must be pre-materialized inside `Phi`.
- Coverage is not correctness, by design.
- Real LLM extraction can violate monotonicity when new conflicting claims overturn old conclusions.
- Representation and access cost are abstracted away, and evidence is primarily theoretical plus an illustrative literary case.

**Curator take:** **3/5.** Conceptually useful and worth keeping as a common-language candidate, but not yet important enough to call a field-shaping evaluation framework. The decisive test is whether the frontier predicts meaningful differences between real memory systems under matched capacity and reasoner.

# ReFind：Structured Memory 需要先击败一个 Competent Raw-State Baseline

**中文** | [English](2608.12888.md) · [返回首页](../../README.md) · [Research Library](../../library/README.md)

[Paper](https://arxiv.org/abs/2608.12888) · **Importance: 4/5**

> **Research delta.** ReFind 的价值不是“BM25 比 memory 强”，而是把 raw-history control 从 single-shot lexical retrieval 升级成 **stateful, multi-round, chat-native access interface**。很多 structured-memory gain 必须重新问：到底来自 representation，还是 baseline interface 太弱？

## Problem

Structured memory 会在未来 query 出现前先 summarization / embedding / graph construction。这样可以预计算 structure，但也可能丢掉后来才重要的原始细节。

过去常见比较是 structured memory vs flat top-k BM25/RAG。但这并不公平：如果 structured system 拥有 session、time、neighbor context、multi-round interaction，而 raw baseline 只有一次 search，那么 gain 很可能混入 interface advantage。

## Mechanism

ReFind 保留 raw timestamped turns，并让 agent 通过更接近真实 chat archive 的 interface 工作：

`form keywords/time scope → turn-level BM25 → inspect local/session context → save evidence → reformulate → skip seen sessions → repeat/stop → answer`

关键 primitive 包括 session-aware ranking、neighboring-turn expansion、temporal filtering 与 seen-session state。

## Closest comparison

最有信息量的 control 有两个：

- **generic-agentic BM25**：允许 multi-round，但没有完整 chat-native controls；
- **one-search control**：保留较强 interface，但取消 result-conditioned iteration。

因此论文可以区分一部分 `interface quality` 与 `multi-round adaptivity` 的作用，而不是只比较 raw vs structured label。

## Decisive evidence

固定 LongMemEval-S/M：

- ReFind: **93.2 / 89.3**
- generic-agentic BM25: **78.7 / 82.2**
- one-search: **84.7 / 68.9**

跨六个任务的 aggregate comparison 也显示 ReFind 对比若干 graph/tree memory baseline 有竞争力；但 EventQA 上 single-shot BM25 略优，说明 result-conditioned interaction 并非每个 workload 都需要。

## What remains unproven

ReFind 最强的结论是“raw baseline 应该更强”，而不是“structured memory 没用”。RippleMem 已经给出一个反例：预建 relation 如果支持 missing-evidence expansion，仍可能在 matched control 下产生额外收益。

下一步应固定 model、原始 evidence、online token、latency、retrieval rounds 与 answer/action budget，比较 raw iterative search、structured retrieval、associative expansion，并把 offline construction/update cost 计入。

此外，精准 refinding 与 acting-agent decision 不是同一 workload；当 query 需要 abstraction、cross-event synthesis 或 procedural reuse 时，raw search 的边界可能不同。

## Field-map consequence

ReFind 把一条 baseline rule 固化下来：

**在声称 semantic/graph memory structure 有价值之前，先和拥有合理 domain-native controls 的 raw-state interface 比。**

因此 `representation` 与 `access interface` 必须分开 attribution。

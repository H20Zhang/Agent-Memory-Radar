# Reconstructing the Right Episode / TSIM

[论文](https://arxiv.org/abs/2608.25655) · [English](2608.25655.md) · [Representation & Organization](../../categories/zh/representation-organization.md)

## Research delta

flat mixed-topic conversation 先把 memory 变成 **state localization / episode integrity** 问题，然后才是 similarity search。TSIM 先重建 coherent episode，再通过 hierarchical views 路由和组装 evidence。

## Problem

一个长 thread 实际上会交错很多互不相关的任务，却没有显式 session boundary。turn-level RAG 很容易抓到语义相似但属于错误 episode 的片段；full context 也不自动知道当前 request 延续的是哪段旧状态。

## Mechanism

TSIM 把 turn stream 切成 temporal-semantic coherent episodes，生成 deterministic episode summary 与 cluster-level views，再先定位相关 cluster/episode，最后组装该 episode 的证据。

## Closest comparison

最有意义的是在**同一个 flat interleaved thread**上与 strong RAG / long-context baseline 比。SCALE-QA 是 evidence surface；Memory Radar 这里关心的是 episode reconstruction mechanism，而不是 benchmark genealogy。

## Decisive evidence

SCALE-QA 有 3,000 个 audited、deterministic four-choice question，覆盖 10 个 domain；128K 全量评估，另有 400 题 1M diagnostic。三个 open/proprietary backend 上，TSIM 都是对应 setting 最优，相比 strongest matched baseline 提升 **5.6–17.6 accuracy points**。

## Main caveat

segmentation、deterministic summary、hierarchical multi-view index、cluster routing 一起变化，所以只能支持 package-level claim。construction/update/query latency、token、美元和能耗也没有对所有 baseline 完整配平。

## Memory lifecycle

`flat turn stream → episode segmentation → summary + hierarchical views → query-time episode localization → reconstructed evidence → answer`

forgetting、revocation、conflict repair、governance 基本没有进入本次评估。

## Why it matters

如果一个 conversation 本质上是很多 interleaved state machine，第一问不应该是“哪个 turn 最相似”，而应该是：**当前任务属于哪一个过去 episode / state？**

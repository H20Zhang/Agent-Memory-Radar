> **Research delta.** DreamBench-SWE makes memory hygiene executable: evidence introduced in earlier sessions must change a later repository patch. It proves that persistent state matters on the constructed tasks, while its preregistered comparisons do not prove that typed consolidation or sleep beats verbatim storage.

## Problem

Recall scores do not show whether an agent applies earlier project state correctly, resolves supersession, abstains from spurious lessons, and produces a valid later code change.

## Mechanism

S1/S2 inject non-inferable project evidence; S3 requires it, and a hidden executable oracle grades the final repository. Ten constructs cover retention, scope, contradiction, update propagation, provenance, synthesis, procedure, spurious lessons, and abstention.

The reference probe preserves immutable raw episodes and derives typed records. Sleep consolidates, extracts failures, replays counterfactuals, repairs contradictions, and suppresses stale state. Read gates memories by status, scope, validity, supersession, risk, staleness, provenance, and type before the wake actor edits the repo.

## Compared with

For the value of persistent state, the closest control is no external memory versus deterministic verbatim storage under the same wake model, task, tools, and read budget. For the typed mechanism, hybrid must beat verbatim, raw-only, and typed-only under matched maintenance compute; it does not.

## Decisive evidence

In v2.1, no memory passes **21/180 (.1167)**, verbatim **82/180 (.4556)**, hybrid **83/180 (.4611)**, and literal-storage Mem0 **97/180 (.5389)**. The earlier evidence therefore changes later executable patches.

Mechanism attribution is negative. Hybrid-versus-verbatim, raw-only, and typed-only preregistered tests all fail to reject; contradiction records appear in **0/180** hybrid/raw reads. Useful-memory precision is also lower for hybrid (**.264**) than verbatim (**.556**).

## Main caveat

The fixture tasks are highly authored and mostly exact recall: 18 of 22 historical traps are recall-verbatim. Only one hosted wake-model family remains feasible, and native Mem0/Supermemory mechanism contrasts fail frozen conformance. Some strata have no no-memory headroom.

Cost accounting is unusually revealing: hybrid uses **174.205M tokens and 12,655 judge calls**, versus **2.209M tokens** for verbatim storage, with p95 latency **3503s vs 505s**. Similar recorded dollar totals therefore hide major maintenance intensity; storage, production operation, hosted-service pricing, and energy remain incomplete.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | Raw sessions and typed records capture project evidence, feedback, constraints, and contradictions. |
| Organize | Sleep consolidates, repairs, replays, and marks stale state. |
| Read | Fixed-budget gates decide what reaches the later coding actor. |
| Update / forget | Raw evidence remains immutable while stale typed state is logically suppressed. |

## Why it matters

Benchmarks should require persistent memory to change later actions, then separately test whether each expensive hygiene mechanism beats a strong verbatim archive.

# Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory

**arXiv:** [2608.07169](https://arxiv.org/abs/2608.07169) · **Published:** 2026-08-07 · **Category:** Memory Learning & Evolution · **Importance:** 4/5 · **AI confidence:** High

**Tags:** `procedural` `structured` `general-agent`

> **TL;DR.** AMD uses memory as a training-free teacher→student transfer channel. Its real design point is not merely “hierarchical memory”: task-, subtask-, and function-level memories are delivered at different control points so a small student gets guidance at a granularity it can actually use.

## Problem

Small 4B–8B tool-using agents often cannot generate enough successful trajectories to bootstrap useful self-memory. A strong teacher can generate successful traces, but simply handing those traces to a weaker student does not guarantee useful transfer: the **teacher–student capability gap** can make a flat memory too abstract, too detailed, or available at the wrong moment.

## Core idea

AMD distills successful teacher trajectories into three complementary memory types: **Workflow memory** for task-level strategy, **Subtask memory** for concrete intermediate behavioral examples, and **Function memory** for per-tool calling conventions and common pitfalls.

The access policy is as important as the hierarchy. Workflow and Subtask memories are retrieved **proactively at task start**; Function memory is retrieved **reactively after a tool-call error**.

## Memory design

| Stage | Design |
|---|---|
| Write | Offline, retain successful teacher trajectories and distill them into workflow, subtask, and function memories. |
| Organize | Three procedural levels aligned to task, subtask, and function control granularity. |
| Read | Retrieve workflow + subtask guidance at task start; retrieve function memory only when the corresponding tool call fails. |
| Update / forget | The evaluated student reads an offline teacher-built memory bank; online student-side consolidation, deletion, and forgetting are not studied. |

## Compared to what

The important comparisons are **ReasoningBank, MemP, and SASM adapted to the same teacher trajectories**. That controls a key confound: AMD is not merely receiving privileged teacher experience that the memory baselines never see.

The remaining delta is how that experience is **re-represented and scheduled for consumption** by the small student.

## Evidence

Across four student models (4B–8B) using GPT-5-mini as teacher, AMD reports average absolute gains over zero-shot of **+27.2pp on AppWorld, +11.2pp on BFCL V3, and +3.4pp on ToolSandbox**, while outperforming the adapted memory baselines.

The paper's analysis is more informative than the headline: **Subtask memory is the largest contributor**, and teacher usefulness depends on **student compatibility as well as teacher capability**. The weaker 4B students benefit most.

## Why it matters

This adds a new boundary to the memory design space: memory can serve as **non-parametric capability distillation across model scales**. The useful principle is that a memory representation should be matched not only to the task, but to the *consumer's capacity and decision granularity*.

That is stronger than “use three memories.” A hierarchy is valuable only if its levels line up with decisions the student can execute.

## Limitations / questions

- This is teacher-assisted capability transfer, not evidence that weak agents can self-evolve from their own sparse experience.
- A stronger teacher is not automatically better; compatibility with the student is a load-bearing condition.
- The memory bank is constructed offline from successful teacher trajectories; long-term online conflict/update/forgetting is not tested.
- Benefits may shrink as student capability rises, since the largest gains occur for weaker students.

**Curator take:** **4/5**. Not field-shaping yet, but the paper gives strong multi-benchmark evidence for a distinct memory role: training-free cross-model capability transfer. The open question is whether this remains useful when teacher trajectories come from a different distribution or when the student must continually revise the transferred memory.

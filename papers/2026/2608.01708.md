# PGMem: Tightly Coupled Persona-Memory Graph for Lifelong Personalized Agents

**arXiv:** [2608.01708](https://arxiv.org/abs/2608.01708) · **Published:** 2026-08-03 · **Category:** Representation & Organization · **Importance:** 3/5 · **AI confidence:** High

> **TL;DR.** PGMem links persona state to its supporting episodic evidence. The strongest ablation is persona-level representation; graph expansion contributes more at longer context but is not the main effect.

## Problem

Separate profile and event memories can lose the evidence behind an evolving preference and retrieve outdated but surface-similar history.

## Core idea

Store Context/Episode and State/Trait nodes in one heterogeneous graph. Source edges preserve provenance; support, contradiction, and shift edges connect evidence to current persona state. Retrieval uses query seeds, graph expansion, and validity-aware ranking.

## Memory design

| Stage | Design |
|---|---|
| Write | Incrementally add event and persona nodes with provenance/evidence edges. |
| Organize | Event-level and persona-level nodes remain distinct but linked. |
| Read | Seed retrieval → evidence expansion → relevance + validity ranking. |
| Update / forget | New evidence can support, contradict, or supersede state; pruning and decay are future work. |

## Compared to what

Full-history, summary, persona-aware, graph, and agentic memory baselines under small-model backbones.

## Evidence

PGMem reports **1.33 / 2.21 / 45.50 / 46.35** across ImplexConv, PrefEval, PersonaMem-32k, and PersonaMem-128k. Without persona-level nodes: **1.21 / 2.02 / 41.09 / 38.80**. Without graph expansion: **1.27 / 2.21 / 44.99 / 43.53**. Construction on ImplexConv uses about **2.254M input + 271k output tokens**.

## Why it matters

It makes provenance part of personalization state, while its ablation warns against attributing the result to graph structure in general.

## Limitations / questions

Synthetic benchmarks, expensive construction, no mature long-horizon pruning/decay, and a modest graph-only ablation on several settings.

**Curator take:** **3/5.** Relevant and useful, but the load-bearing mechanism is evidence-grounded persona representation rather than a general graph-memory breakthrough.

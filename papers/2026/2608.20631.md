# Weighted Memory Tree: Remembering What Matters for Long-Horizon LLM Agents

[← Latest Papers](../../README.en.md#latest-papers) · [Research Map](../../README.en.md#research-map) · [Retrieval & Access](../../categories/retrieval-access.md) · [中文](2608.20631.zh.md)

**Paper:** [arXiv:2608.20631](https://arxiv.org/abs/2608.20631) · **Published:** 2026-08-21 · **Importance:** 3/5 · **Confidence:** Low
**Tags:** `episodic` `hierarchical` `structured` `general-agent`

> **Research delta.** WMT makes selection-driven active retention a stage before retrieval: a task tree scores, decays, folds, and suppresses execution branches before later prompts. The evidence belongs to a coupled within-task working-memory package, not cross-session memory or any single scoring rule.

## Problem

Linear execution history grows with a long task and exposes stale or failed branches without an explicit policy for which state should remain active.

## Mechanism

Each GAIA question starts a task/subtask/action tree. Events receive fixed outcome scores, missed selections decay, branch priorities aggregate, completed trajectories fold into summaries, and low-priority content can be suppressed or reopened. An LLM-selected tree view enters later prompts.

## Compared with

Linear History is the closest end-to-end control under the same model, tasks, tools, instructions, and limits. `Tree + Selection + Summary` is the closest mechanism control, but Full WMT still adds several coupled score, decay, priority, and suppression rules at once.

## Decisive evidence

On the 127-question GAIA-Text subset, linear→WMT accuracy is **20.47→33.86** for Qwen, **24.41→33.07** for Gemma, and **9.45→17.32** for Llama; prompt tokens fall **43.67→32.48M**, **65.27→37.85M**, and **73.96→51.17M**. GAIA's 165 questions include that subset, so they are not independent replication.

Full beats the closest partial package across reported GAIA cells, but component effects are not monotonic: on GAIA-Text Llama, `Tree+Summary` reaches **19.69**, above Full at **17.32**. The retained state changes later actions and final answers within an episode.

## Main caveat

Every question starts fresh; the proposed global promotion path is not evaluated. There are no seeds, paired tests, confidence intervals, per-item traces, or public artifact. The poison experiment uses author-constructed scenarios and assigns low score to already labeled failures, so it does not show robust truth detection.

Prompt-token accounting covers selectors and summaries, and the study reports **6,132 executions / 2.391B prompt tokens** on eight RTX 6000 GPUs. Output tokens, wall time, GPU-hours, dollars, persistent storage, and energy are missing.

## Memory lifecycle

| Stage | Design |
|---|---|
| Write | Actions, observations, events, tasks, and subtasks enter a fresh per-question tree. |
| Organize | Hierarchy, outcome scores, decay, branch priority, folding, and suppression regulate active state. |
| Read | Selected/folded state enters later prompts and changes within-task behavior. |
| Update / forget | Visibility and weights evolve, but durable deletion or cross-session forgetting is not tested. |

## Why it matters

Active working memory can need a retention policy before retrieval, but a package win should not be promoted into a claim about long-term memory or dynamic scoring alone.

# Competence, Not Accuracy：先验证 Judge 能否判别，再让它决定 Skill 是否持久化

[English](2608.18719.md) · [← 最新论文](../../README.md#latest) · [评估与分析](../../categories/zh/evaluation-analysis.md)

**Paper:** [arXiv:2608.18719](https://arxiv.org/abs/2608.18719) · **Importance:** 4/5

> **Research delta.** Reference-free judge 在接管 persistent skill 的准入前，应先证明自己能在**同一道问题内**区分正确与错误尝试；总体 accuracy 或 marginal AUC 可能被题目难度抬高。

## 研究问题

Text-space skill optimizer 会提出新的自然语言 skill document，再由 gate 决定是否替换持久版本。自动 verifier 限制任务范围；LLM judge 虽然更通用，却可能把有害更新写入未来状态。

## Mechanism

论文把 judge 视作 latent solver，推导可用判别信号的 competence floor `c > 1/k`，再把 non-intervening probe 接到真实 SkillOpt run 上。Probe 不改变决策，只记录分数；事后用 verifier label 计算 **within-question ROC-AUC**，消除 item-difficulty confound。

## 最近的公平比较

主比较是在同一批 optimization traces 上对照 marginal AUC 与 within-question AUC；closed loop 再比较 verifier gate、judge gate 与 random gate。它评估的是准入信号，不是 judge-driven optimization 的整体收益。

## 决定性证据

Research math 的 marginal / within-question AUC 为 **0.457 / 0.489**。Factual QA 从 **0.855** 降到 **0.735**，暴露出 0.12 的难度混杂。GPQA 的 **0.840** headline 在计入空答案后变成 **0.626**，matched proxy 下为 **0.547**。

跨 provider 实验重复了 competence 接近 floor 时 gate 接近随机的模式；closed loop 中，该 screen 更像是在预测错误类型，而不是保证更高最终分数。

## 仍未证明什么

超过 competence floor 只是必要条件。估计需要同一道题的多次正负尝试，评估时仍依赖 correctness label；开放式多解任务没有验证。早期只输入 answer letter 的 probe 还制造过 false null，说明 diagnostic 自身也要做 measurement audit。

## 生命周期边界

`candidate skill → shadow judge probe → admission / rejection → persistent skill version`

论文不讨论长期 rollback、lineage 或 retirement。

## 对领域地图的影响

这是一条 **governance early signal**：准入器的能力必须在它实际管理的候选分布上验证，不能拿一般 benchmark accuracy 替代 state-commit evidence。
